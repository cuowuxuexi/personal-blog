# docs/视频

视频只存元数据，视频文件外链托管（如 B 站），博客不存视频本体。`videos.json` 是唯一数据源：首页视频区、`/视频/` 全部视频页和顶栏「视频」都由它自动生成；为空数组时首页视频区和顶栏「视频」都不出现，`/视频/` 页只显示「暂无视频」。

## 文件索引

| 文件 | 说明 |
| --- | --- |
| `videos.json` | 视频条目数组，初始为 `[]`；加视频即追加一条 |
| `index.md` | `/视频/` 全部视频页，只放 `<VideoShelf title="视频" />` |

## 字段

| 字段 | 必填 | 规则 |
| --- | --- | --- |
| `title` | 是 | 非空字符串 |
| `date` | 是 | `YYYY-MM-DD` |
| `duration` | 是 | `m:ss`、`mm:ss` 或 `h:mm:ss` |
| `cover` | 是 | 站内 `/images/videos/…`（文件须存在于 `docs/public/images/videos/`）或 `https://` 外链 |
| `url` | 是 | `https://` 外链 |
| `report` | 否 | 研报代码如 `002714.SZ`，必须对上一份已落地研报 |

校验在 `docs/.vitepress/videos.mjs`，任一条不合规，构建失败并报出下标和字段。
