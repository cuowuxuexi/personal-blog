# 第001期 - 用 AI 整理日常的一周

> 用 AI 压缩信息、自审结论。判断与取舍仍留在自己手里。

## >> 本周在用

### 收件箱与周回顾

这一周尝试把零散待办、会议纪要和阅读摘录集中到固定笔记流里，用 AI 做摘要与归类，而不是让它直接替自己做决定。

## >> 工作流调整

### 一周的整理节奏

1. **收件箱**：全天随手记到一个 inbox 文档
2. **日终**：让模型按「工作 / 学习 / 生活」打标签并提炼 3 条行动项
3. **周末**：回顾行动项完成率，删掉过期噪声

### 工具选择原则

- 优先本地或可控上下文，避免把敏感凭据贴进对话
- 摘要可改、结论自审；模型输出当草稿不是定论

### 一周节奏（示意）

| 节点 | 动作 |
| --- | --- |
| 工作日晚 | 收件箱 → 标签 + 行动项 |
| 周五 | 粗看未完成项 |
| 周日 | 周摘要 + 下周三条 |

- 周回顾时间从「翻聊天记录」变成「改结构化摘要」

## >> 生活切片

### 下一周想试的

## >> 本期小结

AI 适合压缩信息与生成草稿；**判断与取舍仍应留在自己手里**。本页为示例文，可按同样结构替换为真实周记——保留清晰的 h2/h3 分节，右侧「大纲」即可跟着走。
