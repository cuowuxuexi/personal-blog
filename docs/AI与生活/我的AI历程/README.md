# 我的AI历程

「AI与生活」下的独立系列。系列总题为「我的AI历程」：三个**互不合并**的长期篇章，加上与周记同版式的按期记录。

## 文件索引

| 文件 | 说明 |
| --- | --- |
| `index.md` | 系列入口：总题 + 三个篇章链接 |
| `YYYY-MM-DD.md` | 按期历程周记（`type: journey`，期号独立，封面进 `/images/journey/`） |
| `基础设施篇.md` | 独立篇章：底座、协作与发布边界 |
| `工具篇.md` | 独立篇章：日常工具与取舍 |
| `AI开支记录与优化.md` | 独立篇章：实际在付的服务、状态与优化判断 |
| `README.md` | 本说明（不进公开站点） |

按期新开、编号期头（主题 / 封面 / 说明）和条目由本地发布面板维护。具名篇章的期头只改封面和说明，篇章名保持文件对应的稳定标题。新增、重命名或删除具名篇章文件仍走 blog-editor，并同步系列页、`posts.ts` 与侧栏；历程侧栏不再单列「系列入口」。按期新开写入 `posts.ts` 和 `/AI与生活/我的AI历程/` 侧栏的「周记 · YYYY年」。
