# 我的AI历程

「AI与生活」下的独立系列。系列总题为「我的AI历程」：**互不合并**的长期篇章，加上与周记同版式的按期记录。

## 文件索引

| 文件 | 说明 |
| --- | --- |
| `index.md` | 系列入口：总题 + 篇章链接 |
| `YYYY-MM-DD.md` | 按期历程周记（`type: journey`，期号独立，封面进 `/images/journey/`） |
| `基础设施篇.md` | 独立篇章：底座、协作与发布边界 |
| `工具篇.md` | 独立篇章：日常工具与取舍 |
| `cli篇.md` | 工具篇下拉：公开地址 `/html/cli-hub`（`publicHref`）；旧路由跳到完整页 |
| `AI开支记录与优化.md` | 独立篇章：实际在付的服务、状态与优化判断 |
| `README.md` | 本说明（不进公开站点） |

按期新开、编号期头（主题 / 封面 / 说明）和条目由本地发布面板维护。具名篇章的期头只改封面和说明，篇章名保持文件对应的稳定标题。新增、重命名或删除具名篇章文件仍走 blog-editor，并同步系列 `index.md`、本 README、`namedChapterOrder`（及需要时的 `namedChapterNesting`）；`posts` 与历程侧栏由构建期投影生成，不要手改。独立 HTML 图解放 `docs/public/html/` 或现有的 `docs/public/journey-guides/`。普通文章用 `<StandaloneHtml>` 嵌入；整页直达的具名篇章写 `publicHref`，正文用 `<JumpToStandalone />`。
