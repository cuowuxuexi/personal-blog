### 共享 clone 与三 Hermes 写通道

</div>

<WeeklyEntry
  tags="基础设施/协作/Hermes"
  title="共享 clone 与三 Hermes 写通道"
>

az / huizhang / shizun 共用同一份 git clone、同一日记目录。写前 pull，写后 push `main`，默认上站。

- 一天一个 `YYYY-MM-DD.md`，只在末尾追加，不重排旧条。
- 新增日记日文件即可，不必手改 `posts.ts` 或侧栏。
- laptop 通道：共享 clone、三 workspace 软链、白名单 push 脚本已就绪。

💡 基础设施优先保证「能稳定写、能稳定上站」，再谈花活。

</WeeklyEntry>

<div class="weekly-outline-only" aria-hidden="true">

### 公开站与协作本的边界

</div>

<WeeklyEntry
  tags="基础设施/发布/边界"
  title="公开站与协作本的边界"
>

博客仓库既是公开站点源，也是协作写入口。

- 公开正文：周记、AI 历程、投研等成篇内容。
- 协作本：Hermes 按天日记，适合想法、规划、临时判断。
- 默认不把密钥、内网绝对路径、持仓和未脱敏隐私写进公开 docs。

💡 能公开的判断进正文；还在晃的过程先记协作本。

</WeeklyEntry>
