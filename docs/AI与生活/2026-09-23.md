  image="/images/weekly/2026-09-24-03-screenshot-1790245435728png.webp"

OpenAI 和 Anthropic 现在最大的问题，是估值已经跑到了十万亿美元叙事，护城河还停留在「下个模型再强一点」。

这也是它们和 SpaceX 最根本的区别。

SpaceX 今天值多少钱，背后压着二十多年真实世界的积累。火箭、发动机、发射场、供应链、制造体系、政府订单、发射频率，以及 Starlink 已经铺到天上的几千颗卫星。这些东西竞争对手没法靠发一个更好的版本，三个月追平。

前沿模型实验室现在还没有这种东西。

GPT 今天领先，Claude 明天追上，Gemini 后天再刷一次榜。模型能力当然重要，但只要领先优势还以「几个月」为单位，市场份额就随时可以重新洗牌。用户迁移成本也低得吓人，一个 API 地址改了，很多时候公司就换模型了。

所以我很认同 Justin Mateen 这个判断，OpenAI 和 Anthropic 完全可能先成为 5 万亿、甚至 10 万亿美元的公司，然后再面对一个非常尴尬的问题，这么大的公司，到底有什么东西是别人几年都复制不了的？

算力不算，大家都可以买。模型参数不算，架构会扩散。benchmark 更不算，今年的 SOTA 到年底可能已经没人记得。

真正决定这些 frontier labs 最终能不能守住今天估值的，可能已经不在下一代模型还能多拿几分，而在它们能不能趁窗口还开着，把短暂的模型领先，焊死成分发、数据、生态、基础设施和用户迁移成本。

SpaceX 已经花了二十年做这件事。

模型公司现在才刚交第一份作业。

</WeeklyEntry>
