对这张假说卡该怎么读

新品类开辟、国产替代这两条坐标可以留。「直接去欧美」和「三四年被市场看见」过满。更贴成交的写法是：产品在拿认定，销售主场还在国内和新兴市场；欧美公共采购和 III 类植入正在收紧。十亿级公司值多少钱，仍是开放问题，不是已经显化的事实。
