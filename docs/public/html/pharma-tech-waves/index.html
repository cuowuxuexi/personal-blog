一句话

肿瘤应用正站在第四波（ADC / PD-1 双抗），中国机会主要在抗体工程化下半场。药和械是两套价值曲线；DRG / 腾笼换鸟是支付滤镜。嘉宾的「黄金新十年」只进假说区。

三套坐标先分开

需求在换病种，供给在换平台，肿瘤在换武器

需求浪潮

抗感染 → 慢病 → 肿瘤 → 退行性病变

1980 年代后研发进入靶点驱动。三高被管住之后，肿瘤成为主战场；自免、代谢是辅线。

供给平台 · 中国机会

盲筛 → 靶点小分子 → 单抗 → 工程化

上半场找新靶点，美国更强；下半场同一靶点做成 ADC / 双抗，更适合中国。入胞、基因编辑仍看美股。

肿瘤应用 · 当下主线

化疗 → 替尼 → 免疫（PD-1） → ADC ＋ 双抗

这是把供给平台用到癌症上的四波，不是另一套平台史。CAR-T、核药是支线：疗效可以很强，但肿瘤科触达面窄。

投资不能用同一条曲线看药和械

药

找时代级突破，等价值跳升

Biotech 赌创新，Pharma 做商业化。单药专利悬崖一到就会后崩。

械

找新品类，吃后置壁垒

技术不必颠覆。用的人越多，交流、反馈、迭代越强，龙头越难撬。

支付是第三层滤镜，不是药或械的附录

腾笼换鸟

仿制药控费 → 创新药扩容

医药量入为出。集采省下的支付空间，用来把创新药盘子做大。

DRG

把非标服务拉进可比较竞争

同病同价，削弱医生处方权。三板斧里推进最慢、影响最深。展开见「政策」。

来源：雪球《厚雪长波》2026-08-30 期《中国医药资产可能迎来一个"黄金新十年"？》，小宇宙原始节目。数字均为访谈口径。

需求浪潮

1950–60 年代

抗感染

感冒都能死人。研发还在盲筛。

1980–90 年代

慢病 · 三高

找到靶点后，致死病变成吃药能管住的日常。

2000 年后

肿瘤主战场

有的从几个月活到十几年；胃癌、胰腺癌仍难。

下一站 · 嘉宾观点

退行性病变

阿尔茨海默等。尚未成为主战场。

医疗诉求分两层：先救命，再改善体验。胰岛素从一天一针到一周一针，GLP-1 控糖兼减重，都是第二层。嘉宾口径里，当下主战场是肿瘤，自身免疫和代谢是辅线。

供给平台：武器本身也在换代

五六十年代

盲筛

碰运气。对上了是救命药，对不上就作废。

1980 年代后

靶点小分子

先找病因和靶点，再设计分子去抑制或激活。找不到靶点的药，药企一般不敢做。

生物药崛起

多肽 → 单抗

多肽模仿天然激素；1975 年杂交瘤让抗体分子清晰、可以成药。抗体是目前最大的生物药门类。

下半场 · 中国机会

工程化升级

同一靶点做成 ADC、双抗。嘉宾观点：上半场找新靶点美国更强；下半场工程化更适合中国。开辟式（入胞、基因编辑）仍看美股。

成熟技术和新场景不同步。GLP-1 本是控糖工具，找到减重场景后才成为现象级品类——老平台也可以再爆一次。

肿瘤四波

第一波

化疗

飞机扔炸弹，好坏一起杀。多数一线至今仍离不开。

第二波 · 约 2000

替尼类

小分子堵住驱动突变。节目资料：伊马替尼把慢粒五年生存从约 30% 提到约 90%。

第三波 · 2010 后

免疫疗法

CTLA-4 在前，PD-1 是代表：拆掉 T 细胞刹车，出现「超级幸存者」，五年生存曲线尾部被拉高。

第四波 · 当下

ADC ＋ 双抗

给毒素装导航；一个分子打两个靶点。当前研发与交易最热的主线。

主线怎么认

嘉宾的操作性定义是临床触达面：肿瘤科医生几乎人人会碰到 ADC / PD-1；CAR-T、核药只有少数专科在用，所以是支线。不是按市值或论文热度。

八个核心概念

小分子靶向

替尼类（TKI）

后缀 -tinib。堵住癌细胞内部激酶通路。代表药伊马替尼（格列卫）。

升级版化疗

ADC

抗体导航 ＋ 连接子 ＋ 毒素弹头。精确制导，被视为化疗的迭代方向。访谈口径：目前大约二到三成患者能找到特别合适的 ADC。

免疫基石

PD-1 抑制剂

癌细胞利用 PD-1 让 T 细胞别打我。拆刹车后免疫系统重新攻击肿瘤。

1+1>2

PD-1 双抗

同时绑两个靶点，如 PD-1＋VEGF。嘉宾认为这是国产创新药国际竞争力最强的方向之一。

活的药

CAR-T

给患者 T 细胞装导航后回输，体内自我复制。部分血液瘤患者可临床治愈；制备贵、难普及。

老技术新场景

GLP-1

从控糖延伸到减重。说明成熟工具找到新场景，也能再爆一次。

前沿早期

入胞疗法

打细胞内靶点。节目资料称约 85% 疾病靶点在细胞内。目前看美股更多。

出海通道

BD

把海外权益卖给跨国药企：首付款 ＋ 里程碑 ＋ 分成。国产创新药出海主通道。

ADC 为什么这几年突然快了

嘉宾把加速点放在第一三共 DS-8201（约 2019 年前后）：毒素能穿细胞膜，产生旁观者效应，连 HER2 低表达患者也有效，适用面被打开。中国药企随后用工程化优化跟进。即便如此，化疗多数一线仍不可少，ADC 还在逐步替代中（嘉宾观点）。

各癌种不是同一场仗

癌种进展关键疗法为什么
血液瘤部分慢病化，少数临床治愈CAR-T、替尼细胞在血里漂，药容易碰到
肺癌过去十几年进步最大之一EGFR/ALK 替尼、PD-1、部分 ADC先按基因型分层；免疫相对敏感
乳腺癌改善显著HER2 单抗 → ADC → 双抗；三阴有 TROP2 ADC体表器官易早发现
胃癌 / 肝癌有进展但有限尚无突破性疗法确诊时晚期比例高
胰腺癌仍是硬骨头KRAS 等点状突破免疫不敏感，缺好 ADC 靶点

疗效怎么说

慢病化，不是治愈

监管批新肿瘤药，核心看生存期有没有拉长。生活质量是后一层。

药在流程里的位置

能切先切，药从后线往前挪

访谈口径：肝癌、胃癌、肺癌确诊时约六成已晚期，这时创新药就是主疗法；乳腺癌等体表器官早期比例高。化疗多数还在；能找到合适 ADC 的患者大约二到三成。

CAR-T 下一代

两条路都在研发

通用型（工厂化制备）和体内 CAR-T（mRNA/LNP 在体内改装）。走通才会真正普及。

药：前赌 · 中跳 · 后崩

早期

前赌

Biotech 九死一生。颠覆多出自小公司。

→

创意落地

中跳

爆款把公司从百亿级抬到千亿级。稀缺。

→

专利 / 替代

后崩

专利悬崖一到，单药价值回落。要靠下一条管线续上。

Biotech

创新端 · 胆子大

要的是不走寻常路。成了赚十倍五十倍，败了就败了。

Pharma

商业化端 · 四平八稳

体系保证稳定，也抑制创新。两端靠 BD 和收购连接。

嘉宾观点：不存在「30% 增长持续 30 年」的药企。跳升后回到 12%–15% 平台化，再等下一次爆发。礼来抗抑郁 → 沉寂 → GLP-1 二次跳升是样本。最稀缺的是从 Biotech 长成 Pharma 的那几家。

械：新品类 · 后置壁垒 · 农村包围城市

机会来源

新品类开辟

达芬奇手术机器人、结构性瓣膜、动态血糖仪：一家公司带出一条赛道。

价值曲线

越竞争龙头越强

用的人多，交流、反馈、手感互相强化。起搏器半个世纪后仍难撬美敦力。

中国路径

替代 → 出海 → 反攻

先替进口，迭代数代后再去东南亚、中东、南美。直接去美国硬碰没有意义。

「找个好公司拿着不卖」更适合械。投创新药必须引入周期：跳升结束、估值又贵，就没有必要按传统价投一直躺着。支付层见「政策」。

这是滤镜，不是又一条技术浪潮

药和械回答「机会长在哪」；政策回答「支付能不能接住」。腾笼换鸟改的是资源从哪腾出来，DRG 改的是医院怎么花钱。

支付四块

医改三板斧里最硬的一块

DRG

同一病种只付固定标准，把无法标准化的医疗服务强行拉进可比较竞争，削弱医生处方权。集采、医保谈判、DRG 三板斧里，它推进最慢、影响最深。

资源重配

腾笼换鸟

医药是量入为出的行业。访谈口径：过去十年仿制药增长有限，创新药盘子大约扩大十倍，钱来自集采控费省下来的支付空间。

支付预期

医疗升级放缓

人工晶体从 600 档往 2000 档走的节奏变慢。器械自费比例高，对支付预期比药更敏感。

高端药补位

商保

百万级 CAR-T 远超医保上限（约 30 万，嘉宾口径）。政策在推商业健康险补位。

下面不是本博客的当前理解

全部是嘉宾在访谈里的市场判断。本页收录，不代表核验或采纳。要升级成「当前理解」，需另做证据核验。

假说 1

黄金新十年

全指医药 2005–2015 涨十几倍后横盘十年。2015 年医改创新转型框架已落地，行业要从阵痛期进入收获期。

假说 2

BD 均值回归

创新药有奢侈品属性，BD 热潮跟美国财富效应绑在一起。当前规模超历史趋势，增量看国内市场变大和出海切那 96%。

假说 3

国际原创器械显化

多家十亿级公司在引领全球新品类。逻辑 2019–2021 年才启动，未来三四年逐步被市场看见。

假说 4

四个关注方向

国产创新高值耗材与原创器械；国产创新药（ADC/双抗工程化）；美股入胞生物科技；被错杀的低估传统药企。
