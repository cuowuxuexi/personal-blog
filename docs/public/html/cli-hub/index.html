cli篇/ Herdr

GUIDE 04 / Herdr

Herdr

后台终端运行时。助手住在窗格里，你关掉窗口它们还在跑。
入口
项目目录打 herdr
忘了
Ctrl+B ?
范围
工作区 · 窗格 · 前缀键 · CLI
注意
默认前缀是 Ctrl+B

CLI / 每天都用

每天都用

herdr接上默认会话
herdr status看服务还在不在
herdr server stop停掉后台，窗格一起停
herdr --skill打印给助手的说明书

CLI / 会话

会话和远程

herdr session list有哪些会话
herdr session attach接到另一个会话
herdr --session 名字用或开一个命名会话
herdr --remote 主机SSH 接到远端 Herdr

CLI / 窗格

助手从里面推

herdr pane list有哪些窗格
herdr pane split切开一格，不抢焦点
herdr pane run在窗格里跑命令
herdr pane read读窗格输出
herdr agent wait等助手变成某状态
herdr workspace list有哪些工作区
环境只有 HERDR_ENV=1 时，助手才该去推 Herdr。不在窗格里就别装控制。

MODEL / 三层

工作区、标签、窗格

1

workspace

一个项目一个盒子

2

tab

盒子里的一种布局

3

pane

一格真终端

STATE / 状态

侧栏四个字

WORKING

正在干

助手在跑

BLOCKED

卡住了

等你回答或批准

DONE

做完没看

还没被你看过

IDLE

闲着

做完了，也看过了

KEYS / 前缀

先记住这几下

Ctrl+B c新标签
Ctrl+B v向右切开
Ctrl+B -向下切开
Ctrl+B h/j/k/l换窗格
Ctrl+B n / p下 / 上一个标签
Ctrl+B w换工作区
Ctrl+B q脱离，后台继续跑
Ctrl+B ?看全部按键
Ctrl+B [复制模式
鼠标不会前缀也行。点窗格、拖边、右键切开。选中文字就复制，不必 Ctrl+C。
cli篇/ Orca

GUIDE 05 / Orca

Orca

多助手编排桌面。每个助手一个 worktree，终端用 orca 去推。
入口
orca open
忘了
orca --help
范围
worktree · 终端 · 浏览器
注意
多数命令要桌面先开着

CLI / 每天都用

每天都用

orca open打开桌面，等它就绪
orca status运行时还在不在
orca worktree ps各棵树上谁在干活
orca worktree current我现在在哪棵树

CLI / worktree

一棵树一件活

orca worktree create新开一棵，可带助手
orca worktree show看一棵树
orca worktree set改备注、状态
orca worktree list列出树上的活
orca worktree rm从 Orca 和 git 里拿掉

CLI / 终端

对着一格说话

orca terminal list这棵树有哪些终端
orca terminal read读输出
orca terminal send送一行字进去
orca terminal wait等到闲下来或退出
orca terminal create在这棵树里新开一格
orca terminal split切开当前终端

CLI / 浏览器

内置浏览器

orca goto打开一个网址
orca snapshot抓页面，拿到 @e3
orca click点那个元素
orca fill填一格
orca screenshot截一张图
循环先 snapshot，再 click / fill，改完页面再 snapshot。旧的 @e 会过期。

SKILL / 说明书

别靠记忆

orca skills get orca-cli打印和这版匹配的手册
orca skills list这版自带哪些技能
Linux桌面外的裸 orca 有时是读屏软件。那种环境用 orca-ide，不要乱撞。
