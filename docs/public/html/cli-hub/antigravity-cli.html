MODE / 干活姿态

四种安全与审批姿态

Shift+Tab 快速轮转
PLAN

规划模式

只读沙箱。勘察代码与推演方案，禁止任何写操作。

DEFAULT

常规模式

步步确认。改动任何文件或跑命令前弹出确认卡片。

AUTO-EDIT

自动改码

放行编辑，拦截命令。写文件全自动，敏感命令仍需审批。

YOLO

极速放行

全速推进。所有工具与命令直接放行，适合沙盒与独立分支。

PREFIX / 开头

三个魔法开头

指令精准分流
@

注入文件/目录

如 @src/core.ts 梳理流程。遵循 Git 过滤规则，自动排除 node_modules 等干扰项。

!

运行 Shell 命令

输入 !git status 执行并直接返回；空行敲 ! 切换至专属 Shell 交互终端。

?

弹出快捷面板

空行敲 ? 立即在输入框上方挂起快捷按键抽屉，再敲一次或按 Esc 关闭。
