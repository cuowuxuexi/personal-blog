30 秒看懂

Grok Build 是什么？

终端里的全屏聊天机器人。
你打字，它改代码、跑命令。

三种「快捷」

/

斜杠命令

输入 / 弹出菜单

?

命令面板

Ctrl+P 搜一切

@ !

特殊开头

找文件 / 跑命令

第一类

斜杠命令

在输入框打一个 /

每天都用

/help看帮助
/model换模型
/effort思考力度
/new新开一局
/resume回到旧局
/quit离开 Grok

管这一局聊天

/home回欢迎页
/rename给这局起名
/sessions切换会话
/fork分出另一个助手
/rewind回到某句话
/compact压缩旧记忆
/context看还剩多少空间
/session-info这局详情
/delete删掉这局

三种干活模式

1

普通

先问再动手

2

/plan

先写计划

3

/always-approve

不再弹确认

按 Shift+Tab 就能在这几种模式之间轮换。

带走 / 找回来

/copy复制它的回答
/export导出这一局
/share生成分享链接
/find搜索对话
/transcript完整记录

一边干活一边加活

/btw旁白一句，不打断
/queue看排队的话
/tasks后台任务
/loop定时再问一遍
/dashboard多会话看板
/deep-research后台调研
/workflow跑一套流程
/imagine画一张图

记忆和扩展

/remember立刻记住一句
/memory管理记忆
/flush现在就写入记忆
/dream整理旧记忆
/skills技能
/plugins插件
/hooks钩子
/mcpsMCP 连接

账号和杂项

/login登录
/logout退出账号
/settings打开设置
/theme换皮肤
/docs内置说明书
/tutorial新手教程
/doctor体检终端
/usage用量 / 账单
/privacy隐私开关
/feedback反馈
/release-notes更新了什么
/personas人设
