<div class="research-note">
  <strong>本页职责</strong>
  <span>说明市场作为动态反馈系统的基本图景，以及价格的事实地位与警报权。它不主张“价格永远正确”，也不主张“价格毫无信息”。</span>
</div>

<section class="research-section" aria-labelledby="thesis">
  <header class="research-section-head">
    <div><p>THESIS / 当前命题</p><h2 id="thesis">当前命题</h2></div>
  </header>
  <blockquote class="philosophy-quote">
    市场是异质参与者共同生成的反身性系统；价格是重要的市场事实，但不能单独说明企业的长期经营状态和投资回报前景。
  </blockquote>
</section>

<section class="research-section" aria-labelledby="agents">
  <header class="research-section-head">
    <div><p>AGENTS / 异质参与者</p><h2 id="agents">我如何看待市场</h2></div>
  </header>
  <p>市场由大量不同的参与者共同生成。参与者拥有不同的：</p>
  <ul>
    <li>历史经验和认知先验；</li>
    <li>利益目标和现实约束；</li>
    <li>时间尺度和资金期限；</li>
    <li>思考预算和分析能力；</li>
    <li>情绪、习惯和风险承受能力；</li>
    <li>对其他参与者进行递归推测的深度。</li>
  </ul>
  <p>参与者不仅分析企业，也在判断其他人如何分析企业以及可能采取什么行动。这些内部状态和反应方式无法被外部完整观察，因此我不把稳定、精准预测市场作为行动前提。</p>
  <p>市场并非没有信息。价格聚合了参与者的知识、利益和行动，但市场表达的信息维度会随状态变化：</p>
  <ul>
    <li>当参与者足够多样、独立并相互制约时，价格可能包含较丰富的信息；</li>
    <li>当大量参与者共享同一叙事、相互模仿并向同一方向递归时，价格可能主要表达一个角度。</li>
  </ul>
</section>

<section class="research-section" aria-labelledby="reflexivity">
  <header class="research-section-head">
    <div><p>REFLEXIVITY / 反身性</p><h2 id="reflexivity">市场是持续反馈的动态系统</h2></div>
  </header>
  <p>市场还具有反身性。参与者的预期和行动会改变价格，价格又可能影响融资、员工、供应链、消费者和管理层，进而改变企业经营；仓位、盈亏和时间也会反过来影响投资者自己的判断。</p>
  <p>因此，市场不是一个只需发现固定答案的静态系统，而是一个持续反馈、具有路径依赖的动态系统。</p>
</section>

<section class="research-section" aria-labelledby="price">
  <header class="research-section-head">
    <div><p>PRICE / 价格的地位</p><h2 id="price">价格能说明什么，不能说明什么</h2></div>
  </header>
  <p>价格是特定时间、流动性和参与者结构下形成的市场事实。它能直接说明市场如何行动，却不能单独说明：</p>
  <ul>
    <li>企业长期经营状态；</li>
    <li>市场参与者各自的真实理由；</li>
    <li>我的基本面判断是否正确；</li>
    <li>某次上涨或下跌究竟由哪条逻辑造成。</li>
  </ul>
  <p>价格上涨不能自动证明我的原始逻辑正确，价格下跌也不能自动证明企业逻辑失效。</p>
  <p>但是，长期、显著且无法解释的价格反向，可能说明我的模型遗漏了重要变量，必须触发复核。因此：</p>
  <ul>
    <li>价格<strong>没有</strong>企业判断的终审权；</li>
    <li>价格<strong>有</strong>认知警报权；</li>
    <li>价格也直接影响当前行动的吸引力。</li>
  </ul>
</section>

<section class="research-section" aria-labelledby="history">
  <header class="research-section-head">
    <div><p>HISTORY / 历史与周期</p><h2 id="history">历史与周期提供经验先验，不是未来证明</h2></div>
  </header>
  <p>历史和周期提供的是经验先验，而不是未来证明。历史通常重复某些约束、利益结构和群体反应方式，而不是把具体事件原样重演。</p>
  <p>历史价格和历史估值只是参照，不自动形成均值回归。任何回归判断都必须说明：什么经营、行业、政策、资本配置或预期变化，可能推动企业和市场发生改变。</p>
</section>

<section class="research-section" aria-labelledby="boundary">
  <header class="research-section-head">
    <div><p>BOUNDARY / 容易误读的边界</p><h2 id="boundary">这套市场观不意味着什么</h2></div>
  </header>
  <div class="known-unknown">
    <article>
      <h3>它不意味着</h3>
      <ul>
        <li>市场无法研究；</li>
        <li>逻辑没有价值；</li>
        <li>价格永远正确；</li>
        <li>历史经验可以直接当未来保证。</li>
      </ul>
    </article>
    <article>
      <h3>它要求</h3>
      <ul>
        <li>不把价格变化直接当成因果解释；</li>
        <li>分别研究企业事实、市场事实与自身状态；</li>
        <li>不把价格叙事伪装成企业事实；</li>
        <li>不让行动依赖唯一且必须正确的路径。</li>
      </ul>
    </article>
  </div>
</section>

<section class="research-section" aria-labelledby="practice">
  <header class="research-section-head">
    <div><p>PRACTICE / 对研究实践的影响</p><h2 id="practice">对研究实践的影响</h2></div>
  </header>
  <ul>
    <li>把“市场在表达什么”写成可检验的假设，而不是事后叙事。</li>
    <li>遇到显著反向价格时，先问模型是否遗漏变量，而不是先辩护原逻辑。</li>
    <li>判断机会时，同时看估值、基本面方向、主导叙事与可容纳错误的空间。</li>
    <li>观察三个反馈源：企业、市场、自己；尤其警惕盈亏和仓位扭曲判断。</li>
  </ul>
</section>
