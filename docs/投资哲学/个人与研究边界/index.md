<section class="research-section" aria-labelledby="thesis">
  <header class="research-section-head">
    <div><p>THESIS / 当前命题</p><h2 id="thesis">当前命题</h2></div>
  </header>
  <blockquote class="philosophy-quote">
    我是一个认知、资源和资金都有限，但需要保持独立判断与行动的个人投资者；投资既是获得回报的资本实践，也是我探索世界、研究人性和建构人生意义的方式，但不能以摧毁基本生活、生活自主和继续实践的能力为代价。
  </blockquote>
</section>

<section class="research-section" aria-labelledby="self">
  <header class="research-section-head">
    <div><p>SELF / 定位与意义</p><h2 id="self">我如何看待自己与投资的意义</h2></div>
  </header>
  <p>我是一名单兵作战的中长线弱者体系研究者。</p>
  <p>“弱者”不是自我贬低，而是对现实位置的确认：我的信息、资源、组织能力、研究范围和思考预算都有限，不能假定自己天然领先市场。</p>
  <p>我不把“发现市场尚未发现的真相”作为取得回报的必要前提。我更多是在公开事实、已有研究、企业行为和市场价格中学习、比较与选择。我确信大量具体推演可能出错。</p>
  <p>因此，真正适合我的优势不是稳定地预测正确，而是：</p>
  <blockquote class="philosophy-quote">
    稳定地寻找能够容纳错误的研究对象、价格位置和资本结构。
  </blockquote>
  <p>承认有限，不意味着放弃独立判断。它要求我不把自信误认为确定性，不把坚持升级为不可犯错，也不把市场共识直接替代自己的研究责任。</p>
  <p>投资也不仅是财富增长工具。通过企业和市场，我观察资源配置、企业兴衰、制度与行业的互动，以及人的欲望、恐惧、从众、耐心和利益约束。</p>
  <p>投资因此同时具有两类价值：</p>
  <ul>
    <li><strong>资本价值</strong>：获得回报，为独立生活和持续研究提供物质条件；</li>
    <li><strong>认识价值</strong>：帮助我理解世界、人性并修正自己的认知。</li>
  </ul>
  <p>两者分别记账，不能相互替代。认识上的收获不能为资本失败辩护，资本失败也不自动抹去真实的认识收获。</p>
</section>

<section class="research-section" aria-labelledby="review">
  <header class="research-section-head">
    <div><p>REVIEW / 回报、时间与复盘</p><h2 id="review">我如何看待回报、时间与复盘</h2></div>
  </header>
  <p>投资必须面对回报，但实际回报只能评价已经发生的资本结果，不能单独证明原始研究或行动正确。</p>
  <p>复盘需要分开评价：</p>
  <div class="map-stage-card">
    <article>
      <span>01</span>
      <strong>研究评价</strong>
      <p>当时使用的事实、前提和推理是否合理。</p>
    </article>
    <article>
      <span>02</span>
      <strong>行动评价</strong>
      <p>当时的价格、仓位和风险结构是否值得承担。</p>
    </article>
    <article>
      <span>03</span>
      <strong>结果评价</strong>
      <p>资本最终获得了什么回报。</p>
    </article>
    <article>
      <span>04</span>
      <strong>可能分离</strong>
      <p>研究错也可能赚钱；研究合理也可能亏损。</p>
    </article>
  </div>
  <p>一次结果成功不能证明整个过程正确，一次结果失败也不能证明所有认识都没有价值。</p>
  <p>我不设机械持有期限。实际持有时间由企业事实、原有逻辑、市场变化和相对机会共同形成。研究过程可以持续修正认识，却不能事前证明等待一定有效。</p>
  <p>资本占用的事后评价，应把实际回报与承担的风险、持有时间、可比基准和机会成本一起判断。即使一个命题最终成立，如果兑现时间远超原有行动尺度，或者长期排挤了更好的机会，这次资本行动仍可能失败。</p>
</section>

<section class="research-section" aria-labelledby="risk">
  <header class="research-section-head">
    <div><p>RISK / 风险与行动自主权</p><h2 id="risk">我如何看待风险与行动自主权</h2></div>
  </header>
  <p>风险管理的目的不是消灭所有损失，而是避免主动制造可能摧毁基本生活和继续行动能力的结构。</p>
  <p>我不主动把基本生活和继续实践的资格暴露给单一判断或强制清算机制。任何融资安排，即使面对自己判断的极端低估，也不能让合理可以构造的负面价格路径接近终结主要账户。</p>
  <p>这条边界保护的是：</p>
  <ul>
    <li>等待事实展开的权利；</li>
    <li>发现错误后修正的权利；</li>
    <li>继续研究和参与市场的资格；</li>
    <li>基本生活与生活自主。</li>
  </ul>
  <p>无杠杆不等于任何集中和损失都合理。我仍需识别明显的单一企业、行业集中、共同前提和流动性风险；但在完成能力范围内的有限尽责后，我接受仍然无法彻底消除的市场风险、认知错误和极端结果。</p>
  <p>这是我面向未来选择服从的行动边界，也需要由未来真正的极端市场环境检验，不能仅凭文字确认就视为已经形成稳定行为。</p>
</section>

<section class="research-section" aria-labelledby="duty">
  <header class="research-section-head">
    <div><p>DUTY / 有限尽责</p><h2 id="duty">我如何看待有限尽责</h2></div>
  </header>
  <p>我会优先研究重大、明显且能够改变判断或行动的风险，但不试图建立覆盖所有宏观、制度、地缘和黑天鹅情景的完备模型。</p>
  <p>风险研究同样消耗时间和思考预算。当新增分析不再提高区分能力，也不再改变研究结论或可选行动时，应停止无限递归。</p>
  <p>我的责任是降低可避免的毁灭风险，而不是要求世界保证我不受损失。</p>
</section>

<section class="research-section" aria-labelledby="three-views">
  <header class="research-section-head">
    <div><p>RELATION / 三观如何共同指导</p><h2 id="three-views">三观如何共同指导投研</h2></div>
  </header>
  <table class="revision-table">
    <thead>
      <tr><th>三观</th><th>回答的问题</th><th>对投研的作用</th></tr>
    </thead>
    <tbody>
      <tr>
        <td>投资世界观</td>
        <td>世界和市场如何运行，我能认识到什么</td>
        <td>决定如何处理事实、假设、价格和不确定性</td>
      </tr>
      <tr>
        <td>投资价值观</td>
        <td>什么企业值得研究，经营成果如何成为股东回报</td>
        <td>决定研究对象、重点与企业审美</td>
      </tr>
      <tr>
        <td>投资人生观</td>
        <td>我是谁，为什么投资，什么不能牺牲</td>
        <td>决定回报目标、风险边界和行动方式</td>
      </tr>
    </tbody>
  </table>
  <p>因为认识和预测都可能出错，所以我不让行动依赖单一路径；因为我重视企业的生存、经营和股东利益传导，所以我不把好企业、低价格和好投资混为一谈；因为我把基本生活、生活自主和持续行动能力视为不能被牺牲的价值，所以我拒绝主动建立可能摧毁这些能力的结构。</p>
  <p class="philosophy-loop">认识世界与市场 → 选择值得研究的企业 → 在价格和可能路径中形成判断 → 接受企业、市场与结果的反馈 → 修正对世界、企业和自己的认识。</p>
</section>

<section class="research-section" aria-labelledby="research-boundaries">
  <header class="research-section-head">
    <div><p>BOUNDARIES / 研究边界</p><h2 id="research-boundaries">八条最高层约束</h2></div>
  </header>
  <ol class="philosophy-boundary-list">
    <li><strong>事实先于解释</strong>：区分可核验事实、主体陈述、第三方观察、推导数据、研究前提、未来假设和因果解释。</li>
    <li><strong>保留竞争性路径</strong>：同时研究基准、正向和最强合理负向路径，不把一套自洽故事当成唯一未来。</li>
    <li><strong>观察三个反馈源</strong>：分别研究企业事实、市场事实和投资者自身状态，不把价格叙事伪装成企业事实。</li>
    <li><strong>企业质量、价格与回报分开</strong>：不把好企业、低价格和好投资混为一谈。</li>
    <li><strong>研究、行动与结果分开复盘</strong>：最终盈亏不能单独证明原始研究或行动正确。</li>
    <li><strong>仓位服务于可错性</strong>：仓位和融资结构必须保留等待、修正和继续行动的能力；缺少账户信息时，不假设风险承受能力。</li>
    <li><strong>研究有停止条件</strong>：新增分析不再提高区分能力，也不再改变研究结论或可选行动时，停止继续扩展。</li>
    <li><strong>AI 不替代最终判断</strong>：AI 可以揭示事实、假设、反方证据和哲学冲突，但不作命令式买卖、仓位和止损决定。</li>
  </ol>
  <p>这套基座不预先规定机械权重、统一估值阈值、固定持有期限、自动买卖条件或精确路径概率。具体判断必须回到具体企业、价格、事实和账户状态。</p>
</section>

<section class="research-section" aria-labelledby="boundary">
  <header class="research-section-head">
    <div><p>BOUNDARY / 容易误读的边界</p><h2 id="boundary">这套人生观不意味着什么</h2></div>
  </header>
  <div class="known-unknown">
    <article>
      <h3>它不意味着</h3>
      <ul>
        <li>弱者只能跟随市场；</li>
        <li>无杠杆就天然安全；</li>
        <li>研究有意义便可以忽略回报；</li>
        <li>最终赚钱便可以为任何事前风险结构辩护。</li>
      </ul>
    </article>
    <article>
      <h3>它要求</h3>
      <ul>
        <li>承认自身有限，同时承担独立研究与行动责任；</li>
        <li>追求回报，但不以失去基本生活与继续实践资格为代价；</li>
        <li>把研究、行动与结果分开复盘；</li>
        <li>让 AI 辅助揭示，而不是替代最终判断。</li>
      </ul>
    </article>
  </div>
</section>
