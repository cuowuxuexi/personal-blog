<section class="research-section" aria-labelledby="thesis">
  <header class="research-section-head">
    <div><p>THESIS / 当前命题</p><h2 id="thesis">当前命题</h2></div>
  </header>
  <blockquote class="philosophy-quote">
    世界由已经成立的事实构成，而人的认识只能借助有限且可错的证据和逻辑，在多个可能路径之间不断修正。
  </blockquote>
  <p>现实不会因为一套逻辑足够完整、自洽或令人信服，就按照它展开。研究从已经发生且尽可能可核验的事实出发，再加入前提和假设，构造多个可能路径。逻辑的作用，是说明不同路径成立需要什么条件、可能产生什么结果，而不是保证某条路径一定成为现实。</p>
</section>

<section class="research-section" aria-labelledby="kinds">
  <header class="research-section-head">
    <div><p>DISTINCTIONS / 必须区分的东西</p><h2 id="kinds">我必须区分的五类命题</h2></div>
  </header>
  <div class="map-stage-card">
    <article>
      <span>01</span>
      <strong>可核验事实</strong>
      <p>已经发生，并能说明来源、时间和口径的事项。</p>
    </article>
    <article>
      <span>02</span>
      <strong>主体陈述</strong>
      <p>公司、管理层或第三方对事实和未来的表达。</p>
    </article>
    <article>
      <span>03</span>
      <strong>研究前提</strong>
      <p>为了展开分析而暂时接受的命题。</p>
    </article>
    <article>
      <span>04</span>
      <strong>未来假设</strong>
      <p>尚未发生、需要后续事实检验的路径。</p>
    </article>
  </div>
  <p>此外还有<strong>因果解释</strong>：我对事实为什么发生、彼此如何关联的理解。五类命题混用时，研究最容易把“看起来合理”误当成“已经成立”。</p>
  <p>命题是否成立，与我对它有多大信心是两回事。即使一个事实已经发生，我对其来源、口径和意义的理解仍可能出错。</p>
</section>

<section class="research-section" aria-labelledby="falsify">
  <header class="research-section-head">
    <div><p>EVIDENCE / 证据如何起作用</p><h2 id="falsify">未被证伪不等于获得支持</h2></div>
  </header>
  <p>未被证伪，只说明某个命题仍然可能成立，不等于它获得了新的正面支持。只有当新事实具有区分力，或者一个命题通过了原本可能使它失败的检验，它的可信度才应提高。</p>
  <p>承认认识可错，不等于放弃研究。研究的价值在于：</p>
  <ul>
    <li>暴露前提；</li>
    <li>比较路径；</li>
    <li>识别失效条件；</li>
    <li>减少无意识地把假设当成事实。</li>
  </ul>
</section>

<section class="research-section" aria-labelledby="boundary">
  <header class="research-section-head">
    <div><p>BOUNDARY / 容易误读的边界</p><h2 id="boundary">这套认识论不意味着什么</h2></div>
  </header>
  <div class="known-unknown">
    <article>
      <h3>它不意味着</h3>
      <ul>
        <li>市场无法研究；</li>
        <li>逻辑没有价值；</li>
        <li>任何说法都同等可信；</li>
        <li>可以无限推迟判断。</li>
      </ul>
    </article>
    <article>
      <h3>它要求</h3>
      <ul>
        <li>以可错性为前提研究世界；</li>
        <li>不把逻辑自洽当成事实成立；</li>
        <li>不让行动依赖唯一且必须正确的路径；</li>
        <li>把“我有多确信”与“命题是否成立”分开记账。</li>
      </ul>
    </article>
  </div>
</section>

<section class="research-section" aria-labelledby="practice">
  <header class="research-section-head">
    <div><p>PRACTICE / 对研究实践的影响</p><h2 id="practice">对研究实践的影响</h2></div>
  </header>
  <ul>
    <li><strong>事实先于解释</strong>：动笔前先标明材料属于事实、陈述、前提、假设还是解释。</li>
    <li><strong>保留竞争性路径</strong>：同时研究基准、正向和最强合理负向路径，不把一套自洽故事当成唯一未来。</li>
    <li><strong>提高可信度需要区分力</strong>：新材料若对多条路径同样兼容，它不能单独抬升某一条路径的地位。</li>
    <li><strong>研究有停止条件</strong>：当新增分析不再提高区分能力，也不再改变结论或可选行动时，停止无限递归。</li>
  </ul>
</section>
