<section class="invest-hub-section" aria-labelledby="philo-core">
  <header class="invest-hub-section__head">
    <div>
      <p>THESIS / 总纲</p>
      <h2 id="philo-core">当前总纲</h2>
    </div>
    <span>持续补充 · 截至 2026-08-10</span>
  </header>
  <blockquote class="philosophy-quote">
    我以有限且可错的个体身份进入市场，以事实为认识起点，以企业的生存、创造和价值传导为研究核心，在不依赖精准预测和单一路径的前提下，寻找能够容纳错误的行动位置。投资既服务于资本回报，也服务于独立生活以及对世界与人性的长期探索；任何行动都不应以摧毁基本生活、等待能力、修正能力和继续实践的资格为代价。
  </blockquote>
  <ul>
    <li><strong>投资世界观</strong>：如何看待世界、市场、价格和认识边界。</li>
    <li><strong>投资价值观</strong>：如何看待企业、管理层、行业生态和股东回报。</li>
    <li><strong>投资人生观</strong>：如何看待自己、投资的意义、风险和行动边界。</li>
  </ul>
  <p>三者的关系是：世界观决定我如何认识现实，价值观决定我选择研究什么，人生观决定我为什么参与市场以及什么不能被牺牲。</p>
</section>

<section class="invest-hub-section" aria-labelledby="philo-boundary">
  <header class="invest-hub-section__head">
    <div>
      <p>BOUNDARIES / 研究边界</p>
      <h2 id="philo-boundary">最高层约束摘要</h2>
    </div>
    <a href="/投资哲学/个人与研究边界/#research-boundaries">完整八条 →</a>
  </header>
  <ol class="philosophy-boundary-list">
    <li><strong>事实先于解释</strong>：先分清事实、陈述、前提、假设与因果解释。</li>
    <li><strong>保留竞争性路径</strong>：同时保留基准、正向与最强合理负向路径。</li>
    <li><strong>观察三个反馈源</strong>：企业事实、市场事实、投资者自身状态分开看。</li>
    <li><strong>企业质量、价格与回报分开</strong>：不把好企业、低价格和好投资混为一谈。</li>
    <li><strong>研究、行动与结果分开复盘</strong>：盈亏不能单独证明过程正确。</li>
    <li><strong>仓位服务于可错性</strong>：结构必须保留等待、修正和继续行动的能力。</li>
    <li><strong>研究有停止条件</strong>：新增分析不再提高区分力时停止扩展。</li>
    <li><strong>AI 不替代最终判断</strong>：可揭示冲突与反证，不作命令式买卖决定。</li>
  </ol>
</section>

<section class="invest-hub-section" aria-labelledby="philo-loop">
  <header class="invest-hub-section__head">
    <div>
      <p>LOOP / 实践循环</p>
      <h2 id="philo-loop">三观如何共同指导投研</h2>
    </div>
  </header>
  <p>因为认识和预测都可能出错，所以我不让行动依赖单一路径；因为我重视企业的生存、经营和股东利益传导，所以我不把好企业、低价格和好投资混为一谈；因为我把基本生活、生活自主和持续行动能力视为不能被牺牲的价值，所以我拒绝主动建立可能摧毁这些能力的结构。</p>
  <p class="philosophy-loop">认识世界与市场 → 选择值得研究的企业 → 在价格和可能路径中形成判断 → 接受企业、市场与结果的反馈 → 修正对世界、企业和自己的认识。</p>
</section>

<section class="invest-hub-section" aria-labelledby="philo-compress">
  <header class="invest-hub-section__head">
    <div>
      <p>COMPRESS / 最终压缩</p>
      <h2 id="philo-compress">一句话版本</h2>
    </div>
  </header>
  <blockquote class="philosophy-quote">
    我以事实为起点，以可错性为前提认识世界和市场；我研究企业在行业中的生存、经营和股东利益传导，而不把好企业、低价格和好投资混为一谈；我承认自己有限，但仍承担独立判断和行动的责任。我的目标不是稳定地预测正确，而是稳定地寻找能够容纳错误的位置。投资既要接受资本回报的检验，也承载我探索世界和人性的意义；我可以面对不确定性和有限尽责后的剩余风险，但不主动建立会摧毁基本生活、等待能力和继续实践资格的结构。AI 可以帮助我揭示事实、假设、竞争路径和认知冲突，但不能代替我的最终判断。
  </blockquote>
</section>
