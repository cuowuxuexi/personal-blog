<section class="research-section" aria-labelledby="thesis">
  <header class="research-section-head">
    <div><p>THESIS / 一句话版本</p><h2 id="thesis">先把结论说完</h2></div>
  </header>
  <blockquote class="philosophy-quote">
    决定股价高度的是叙事——市场此刻信的那个终局；决定股价涨跌的是叙事的变化；股价实际停在哪，由 A 股的拍卖机制决定；以上全部由逻辑推出、用案例检验，不用案例归纳。
  </blockquote>
  <p>翻成人话：<strong>股价买的不是今年的业绩，是市场相信的“最后能做多大”。</strong>业绩涨了股价不一定涨，因为大家早就信了；业绩没涨股价也可能涨，因为大家对“最后能做多大”的看法变了。想赚超过市场平均的钱，只有一条路——在别人改变看法之前，先看对终局。</p>
  <p>这里的“叙事”不是讲故事。这套框架的定义有三道门槛，缺一条都不算：<strong>基于逻辑</strong>——能从 DCF 一步步推出来，不是先贴“成长股 / 周期股 / 价值股”的标签再倒推；<strong>可证伪</strong>——能被时间检验，“这家公司有想象空间”不是叙事，“终局利润是现在的 3 倍”才是；<strong>可量化</strong>——能算出数，给定终局高度和折现率就有唯一的合理 PE，反过来给定 PE 能反算市场信的终局。它比通常说的“预期差”窄得多：预期差盯的是下一季和明年，叙事只回答一个问题——市场信的终局，是现在的几倍。</p>
</section>

<section class="research-section" aria-labelledby="spine">
  <header class="research-section-head">
    <div><p>SPINE / 骨架</p><h2 id="spine">一条公理、五根承重柱</h2></div>
    <span>整套理论就是 DCF 求两次导，再加一层交易机制和一条元规则</span>
  </header>
  <p>下面六条不是并列的六点心得，而是一条推导链：DCF 的静态解给出<strong>高度</strong>，动态解给出<strong>涨跌</strong>，交易机制解释<strong>应然与实然的差</strong>，方法论保证前面三步<strong>不是事后拟合</strong>。第 0 层是公理，第 1 层是五根承重柱，其余概念都是派生——抽掉任何一根柱子，这条链就断了。</p>
  <ol class="philosophy-boundary-list">
    <li><strong>公理 · DCF：股价 = 目之所及所有未来现金流的折现值。</strong>买股票不是买今年的业绩，而是一个人把公司目之所及的全部未来折到今天、打包卖给另一个人。PE、PB 这些常用指标不是另一套东西，都是 DCF 在特定条件下的简化版。这把尺子的用法不是算准价格，而是反算市价里已经写了什么假设。→ <a href="/html/dcf-eli5">DCF 画布</a></li>
    <li><strong>承重柱 1 · 叙事就是终局，增速只是过程。</strong>估值几乎只由“天花板有多高”决定，多久到达不重要：一棵树 3 年长大还是 8 年长大，价差小得出奇——长得快的那几年结果少，算“每个果子值多少钱”时分母也小，两边几乎抵消。所以合理动态 PE 只由两个数决定：<strong>天花板是现在的几倍</strong>和<strong>折现率取多少</strong>。反过来，知道今天的 PE 就能反算出市场信的天花板——这是整套框架最常用的一个动作。→ <a href="/html/zou-endgame">空间叙事与终局</a></li>
    <li><strong>承重柱 2 · 折现率就是必要收益率。</strong>它是投资者肯把钱交出去、并且拿着不动的最低年化回报，相当于债券的到期收益率。A 股取 10%、美股取 8%，不是拍出来的：用光伏、煤炭、水电、白酒等大跨度案例复盘，00 年代、10 年代、20 年代拟合度都高，长期有均值回归。它不随无风险利率等额变化——无风险利率下降的原因，往往正是风险溢价上升的原因；“这棵树能不能结果”和“今年利率多少”背后是同一片天气。所以利率下行带来的是结构分化，不是普涨：抗风险强的受益，弱的受损，方向由协方差决定。→ <a href="/html/zou-discount-rate">折现率与分母端</a></li>
    <li><strong>承重柱 3 · 拍卖机制：应然到实然的最后一跳。</strong>DCF 算出的是估值“应该”在哪；股价“实际”停在哪，中间还隔着一层价格形成机制。A 股难以做空，悲观者的票投不出去，定价就从“多空对冲后的平均预期”变成“从最乐观的资金开始依次出清”的拍卖，于是<strong>股价 = 中线（基本面决定的平均预期）+ 截距（交易机制带来的漂移）</strong>，流动性本身成了定价要素。它解释了为什么天花板越算不清、流动性越泛滥，越容易被推着涨。可以不参与这套正反馈，但不能不知道它。→ <a href="/html/zou-auction">拍卖机制</a></li>
    <li><strong>承重柱 4 · 叙事变化 = 超额收益。</strong>如果 t₁ 仍在演绎 t₀ 的叙事，两个时点的股价之比严格等于 (1 + r)——与业绩是增长、下滑还是周期震荡无关。哪怕利润多了 30%，只要这笔增长早就写在剧本里，股价也只涨那 10%。所以收益要拆成“必要收益 + 叙事差”：<strong>兑现叙事赚折现率，改变叙事才赚超额收益</strong>。长牛不是稳定增长的结果，是几次看法改变拼出来的台阶——这也是大部分人赚不到长牛的钱的原因。→ <a href="/html/zou-alpha">叙事变化与超额收益</a></li>
    <li><strong>承重柱 5 · 研究方法论：这套框架的元规则。</strong>社会科学没法控制变量，同一个现象总有好几种都能自圆其说、结论却相反的解释。应付办法只有两条：<strong>以逻辑推理为主线，用统一的框架解释尽可能多的现象</strong>。判据不是“拟合结果显著”，而是能不能证伪、能不能预测。连投 5 次硬币都是正面，该做的不是押正面也不是押反面，是先检查硬币是否均匀；相关性也不能传递——爸爸和孩子有血缘、孩子和妈妈有血缘，推不出爸妈有血缘。→ <a href="/html/zou-method">研究方法论</a></li>
  </ol>
  <p class="philosophy-loop">DCF 给出“应该值多少”（高度）→ 对时间求导给出“为什么涨跌”（变化）→ 拍卖机制解释“为什么实际价格常常不在应该的位置”（应然与实然的差）→ 方法论保证前面三步是推出来的，不是事后拟合的。</p>
</section>

<section class="research-section" aria-labelledby="practice">
  <header class="research-section-head">
    <div><p>PRACTICE / 对研究实践的影响</p><h2 id="practice">看 A 股时多出来的四个习惯</h2></div>
  </header>
  <div class="map-stage-card">
    <article>
      <span>01</span>
      <strong>先反算，再判断</strong>
      <p>看到一家公司先别问“便宜吗”，问“这个价格里，市场信的终局是现在业绩的几倍”。60 倍市盈率、10% 折现率，隐含的是 12 倍终局；这个终局你信不信，才是问题。</p>
    </article>
    <article>
      <span>02</span>
      <strong>利好不涨，是警报</strong>
      <p>如果一家公司利好不断、股价不动，大概率不是市场迟钝，而是预期已经打满，任何利好只够维持预期。景气度投资在行情前半段极有效，后半段常常是反指。</p>
    </article>
    <article>
      <span>03</span>
      <strong>兑现不是利好</strong>
      <p>业绩如期兑现，股价只涨折现率，走出“厂”字形；被证伪，走“A”字形。长牛不是稳定增长的结果，是几次看法改变拼出来的——所以大部分人赚不到长牛的钱。</p>
    </article>
    <article>
      <span>04</span>
      <strong>大部分时候只赚折现率</strong>
      <p>叙事变化可遇不可求。承认这一点，就不会把每一次业绩超预期都当成买入理由，也不会把没有超额收益的“等待期”当成失败。</p>
    </article>
  </div>
</section>

<section class="research-section" aria-labelledby="boundary">
  <header class="research-section-head">
    <div><p>BOUNDARY / 容易误读的边界</p><h2 id="boundary">这套框架不是什么</h2></div>
  </header>
  <div class="known-unknown">
    <article>
      <h3>它不是</h3>
      <ul>
        <li>选股清单或买卖信号；</li>
        <li>一套能算准价格的模型——DCF 在这套框架里是价值观和尺子，不是计算器；</li>
        <li>对任何具体公司的判断，画布里的案例只描述历史股价隐含的预期；</li>
        <li>“预期差”的同义词——它只指对终局空间与折现率的判断。</li>
      </ul>
    </article>
    <article>
      <h3>它要求</h3>
      <ul>
        <li>先知道股价此刻隐含的叙事，再谈方向；</li>
        <li>把“必要收益”和“超额收益”分开记账；</li>
        <li>承认拍卖机制会让价格长期偏离“应该”的位置；</li>
        <li>用推理搭框架，用案例检验，接受被证伪。</li>
      </ul>
    </article>
  </div>
  <p>“公理 / 承重柱 / 派生”的层级划分是整理者对这套理论结构的归纳，不是原文用语；判据是“抽掉后整套理论是否仍然成立”。</p>
</section>
