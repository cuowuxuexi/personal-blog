# 写在投资笔记开始之前

> **非投资建议**：本文为个人记录模板与写作约定，不构成任何投资建议。据此决策风险自负。

## 为什么单独开板块

投资相关笔记需要固定落点：便于按时间回顾，也便于与「AI与生活」的随笔分开。左侧时序列表只显示本板块内容，不会与另一板块串栏。

阅读骨架固定为：

| 区域 | 作用 |
| --- | --- |
| 左栏 | 当前板块年份折叠 + 时间序列 |
| 中栏 | 正文（本页） |
| 右栏 | 本页指引（大纲） |

## 写作约定

每篇笔记建议包含：

1. **背景**：观察窗口、相关资产或主题（无需敏感账户细节）
2. **框架**：使用的分析维度或 checklist
3. **记录**：事实与数据出处
4. **复盘点**：事后可对照的假设

### frontmatter

```yaml
---
title: 文章标题
date: 2026-08-08
category: 投资
description: 一句话摘要（首页与板块列表会用）
# cover: /covers/example.jpg   # 可选；无图则不显示封面
---
```

新增文件后请同步两处：

1. `docs/.vitepress/posts.ts`（首页最近更新 + 板块列表）
2. `.vitepress/config.mts` 的 `/投资/` sidebar

### 标题层级建议

- `##`：主节（会进入右侧「本页指引」）
- `###`：小节
- 引用块用于免责、摘录与关键提醒

## 风险与边界

- 不记录真实账户密码、API Key 或可识别的隐私仓位细节
- 引用第三方研报/新闻时注明来源
- 页面与页脚已标注**非投资建议**

更多说明见 [关于](/关于) 页。
