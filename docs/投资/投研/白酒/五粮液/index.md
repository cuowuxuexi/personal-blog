<section class="research-section" aria-labelledby="why">
  <header class="research-section-head">
    <div><p>WHY / 为什么研究</p><h2 id="why">为什么研究五粮液</h2></div>
  </header>
  <p>我把它看成行业老二，主要靠普五和线下经销商赚钱；行业在缩量跌价。左侧持有时的判断是：去年的财务洗澡压实了估值，产品本身没有大问题，终局利润不超过 2022 年。</p>
  <p>揭标时，市值大约 2739 亿。后面走过一轮天花板和利润分档，但那些档位都默认「洗澡让五粮液轻装上阵」。2026-10-12 回到准备阶段，先把这个前提拆开验证。</p>
</section>

<section class="research-section" aria-labelledby="thesis">
  <header class="research-section-head">
    <div><p>PROPOSITION / 当前命题</p><h2 id="thesis">当前要验证的命题</h2></div>
    <span>截至 2026-10-12</span>
  </header>
  <p>原假设是：同价位品牌都背着经销商库存压力；五粮液借管理层问题把它一次挤掉，后续反而有更大空间。</p>
  <p>最新判断改成：需求不会一直这么悲观；千元带要靠竞争。五粮液在大家看空时投入资源、优化经销体系，有机会拿到并留住更大的市场。负现金流只是找原因，不推出到期必然修复。</p>
  <p>随后又改了一刀：投入的不只它一家。汾酒、迎驾、茅台 2026 年上半年销售费用也高于 2024 年同期。研究重点从「它敢不敢投」转成「谁的投入更有效、是否在同一价格带形成可持续份额优势」。战略成效仍待验证。</p>
</section>

<section class="research-section" aria-labelledby="gates">
  <header class="research-section-head">
    <div><p>GATES / 七道关</p><h2 id="gates">七道关现在过到哪里</h2></div>
    <span>截至 2026-10-12</span>
  </header>
  <div class="map-stage-card">
    <article><span>01</span><strong>共同压力 · 有支持</strong><p>2025 年调查中 58.1% 的渠道受访者称库存增加，2026 年仍有 56.6% 称倒挂加剧；2022 年已见多品牌清旧货。各家负担是否一样大、是否都起于 2020—2021 年，还没证成。</p></article>
    <article><span>02</span><strong>问题显性化 · 已确认</strong><p>2025 年前三季度营收更正 609.45 → 306.38 亿，归母 215.11 → 64.75 亿；公告称不影响现金流量表。更正不等于同额退款、退货或义务取消。</p></article>
    <article><span>03</span><strong>约束新增压力 · 有支持</strong><p>官方称按动销和库存优化配额、调整收款政策；2025 年底已停发货并给返利，2026 年目标改为动销与份额。实际投放量和内部考核是否重设，未见数据。</p></article>
    <article><span>04</span><strong>旧库存真实消化 · 方向混杂</strong><p>监管商品款项 263.15 → 239.73 亿，净减少；厂家主品牌库存却由 25118 升到 26607 吨。缺渠道盘点、真实动销，以及监管款项的进出桥接。</p></article>
    <article><span>05</span><strong>经销商重新赚钱、主动补货 · 未证</strong><p>双节样本里普五库存压力缓和、周转好于高度国窖，但渠道盈利仍偏弱；大商略盈利，小商亏损。缺同地区连续的经销商净利润和自愿补货记录。</p></article>
    <article><span>06</span><strong>厂家的经常性支持下降 · 反向</strong><p>2026 年上半年销售费用 63.22 亿，其中促销 44.92 亿；费用率 22.25%，2019—2024 年同期大约 9.5%—10.6%；经营现金流 −21.54 亿。费用率上升有收入下降的分母，但费用金额也在涨。</p></article>
    <article><span>07</span><strong>比同行改善更多 · 未证</strong><p>老窖、洋河也在按动销控量，老窖中高档厂家库存年内降 21.69%；汾酒、迎驾、茅台也在加投入。缺同产品、同地区可比的全链库存与负担序列。</p></article>
  </div>
  <p>七道关都过了，才谈得上「既有终局更可达」。现在还谈不上。</p>
</section>

<section class="research-section" aria-labelledby="now">
  <header class="research-section-head">
    <div><p>NOW / 当前理解</p><h2 id="now">当前理解</h2></div>
  </header>
  <ul>
    <li>五粮液应先看成靠普五和线下经销商赚钱的千元带酒厂，不要先看成已经洗完澡、轻装上阵的公司。</li>
    <li>2025 年前三季度更正是已确认事实。更正本身不证明库存已经出清，也不证明经销商已经重新赚钱。</li>
    <li>监管商品款项净减少和厂家主品牌库存上升同时存在，旧库存是否真实消化，现在只能写成方向混杂。</li>
    <li>2026 年上半年销售费用和促销都在涨，经常性支持下降这一关是反向的。</li>
    <li>它不是唯一加投入的酒厂。当前命题是逆周期投入、争千元带；要验证的是投入是否更有效，不是它有没有投。</li>
    <li>历史轮次里算过卖酒净利润三档，那些计算默认洗澡等于轻装上阵。本轮准备阶段没有把它们升成当前结论。</li>
  </ul>
</section>

<section class="research-section" aria-labelledby="open">
  <header class="research-section-head">
    <div><p>OPEN / 尚未解决的问题</p><h2 id="open">尚未解决的问题</h2></div>
  </header>
  <div class="known-unknown">
    <article>
      <h3>准备阶段仍缺的证据</h3>
      <ul>
        <li>监管商品的完整业务合同、货权与库存地点，以及退货、退款、担保回购责任是否和厂家商品酒吨数重合</li>
        <li>监管商品款项从期初到期末的完整桥接：新增、确认收入、退款、价格调整；不能从净减少额推定确认收入或真实动销</li>
        <li>同价位、同地区、同规格的厂家投放、渠道盘点、真实动销、经销商资金占用与利润的连续序列</li>
        <li>五粮液与泸州老窖在真实库存消化、实际渠道支持和取消未来义务上的可比差异</li>
        <li>2020—2021 年库存从哪来、后来怎么再积累；现有材料里既有遗留库存，也有低库存判断</li>
        <li>管理层事件是否触发更正的官方说明；未披露不能写成公司主动策略</li>
      </ul>
    </article>
    <article>
      <h3>本页故意还没做</h3>
      <ul>
        <li>把历史利润档重新写成当前价格判断</li>
        <li>目标价、买卖、仓位或止损</li>
      </ul>
    </article>
