    <div><p>WHY / 为什么研究</p><h2 id="why">为什么研究药明康德</h2></div>
  </header>
  <p>我希望理解：一家以 CRDMO 为核心叙事的公司，究竟承接了创新药链路中的哪些能力？它的生意是不是“越早进入、越容易留下、越可能接到后端放量”？</p>
  <p>在回答这些问题之前，我必须先搞清楚创新药怎么做出来，以及 CRO / CDMO / CRDMO 分别是什么。否则公司材料会变成名词堆叠。</p>
