<div class="research-note"><strong>核心区分</strong><span>创新药、原研药、仿制药不是一条简单的“三阶段改名”。它们分别描述创新属性、来源身份和参照关系，需要与药物类型、生命周期分开看。</span></div>

<section class="research-section" aria-labelledby="identity">
  <header class="research-section-head"><div><p>IDENTITY / 身份维度</p><h2 id="identity">先问的是哪一个维度</h2></div></header>

  <div class="knowledge-concept-grid">
    <article><span>创新属性</span><h3>创新药</h3><p>回答“这是不是一个达到相应新药门槛的创新”。具体注册分类和监管口径需要按地区与时期核实。</p></article>
    <article id="origin"><span>开发来源</span><h3>原研 / 创新者产品</h3><p>回答“谁最初完成了这只产品的开发与获批”。原研身份不会因专利或其他保护到期自动消失。</p></article>
    <article id="reference"><span>监管参照</span><h3>参比制剂</h3><p>它是仿制药评价使用的监管参照。原研产品通常是优先来源，但是否被列为参比制剂是另一项需要查询目录或监管指定的事实。</p></article>
    <article><span>参照开发</span><h3>化学仿制药</h3><p>围绕依法确定的参比制剂，按适用监管要求证明药学等同性或可比性与生物等效性；不等于默认重做完整临床疗效试验。</p></article>
    <article><span>生物药对应路径</span><h3>生物类似药</h3><p>生物大分子无法按化学小分子那样复制成完全相同结构，因此走生物类似性评价，不与化学仿制药混为一类。</p></article>
  </div>
</section>

<section class="research-section" aria-labelledby="lifecycle">
  <header class="research-section-head"><div><p>LIFECYCLE / 生命周期</p><h2 id="lifecycle">同一只原研药不会在专利到期后“变成仿制药”</h2></div></header>

  <div class="knowledge-chain" role="group" aria-label="创新者产品从研发到保护减弱和替代竞争的典型生命周期">
    <span><small>研发阶段</small><strong>创新药项目</strong></span><i aria-hidden="true">→</i>
    <span><small>获批上市</small><strong>原研 / 创新者产品</strong></span><i aria-hidden="true">→</i>
    <span><small>保护期内</small><strong>专利与其他独占保护</strong></span><i aria-hidden="true">→</i>
    <span><small>保护减弱以后</small><strong>原研仍可继续销售</strong></span><i aria-hidden="true">＋</i>
    <span><small>替代产品进入</small><strong>化学仿制药 / 生物类似药</strong></span>
  </div>
  <div class="research-note"><strong>独立监管节点</strong><span>仿制药使用哪一个参比制剂，要另查监管目录或指定；它不是“创新药获批后自动获得”的身份。</span></div>
  <p>“创新药”与“原研产品”可能同时描述同一产品；“仿制药”描述后来参照监管确定对象开发的另一类产品。研究公司时还要继续问药物类型、保护状态与市场替代程度。</p>
</section>

<section class="research-section" aria-labelledby="payment">
  <header class="research-section-head"><div><p>PAYMENT / 支付机制</p><h2 id="payment">医保谈判与集采作用在不同竞争情境</h2></div></header>

  <div class="payment-map">
    <article>
      <span>独家或创新产品更常先遇到</span>
      <h3>医保谈判</h3>
      <div class="knowledge-chain knowledge-chain--compact"><span><small>药企让出</small><strong>更低价格</strong></span><i>↔</i><span><small>支付端提供</small><strong>医保目录与报销准入</strong></span></div>
      <p>“有谈判空间”不等于疼得轻。谈判可以显著降低已上市创新药价格，但也可能改善可及性和放量条件。</p>
    </article>
    <article>
      <span>多家可替代产品更常遇到</span>
      <h3>国家集采</h3>
      <div class="knowledge-chain knowledge-chain--compact"><span><small>药企让出</small><strong>更低报价</strong></span><i>↔</i><span><small>采购端提供</small><strong>约定采购量</strong></span></div>
      <p>核心是以量换价。历史主场是已有多家供应、尤其通过一致性评价的化学仿制药；具体扩围仍需按品种核实。</p>
    </article>
  </div>
</section>

<section class="research-section" aria-labelledby="transmission">
  <header class="research-section-head"><div><p>TRANSMISSION / 传导</p><h2 id="transmission">支付政策怎样间接传到 CXO</h2></div></header>

  <div class="transmission-map" aria-label="支付政策传导到 CXO 的路径">
    <div class="transmission-map__step transmission-map__step--direct"><small>政策工具</small><strong>医保谈判 / 集采</strong><p>改变准入、药价或采购量</p></div>
    <i>→</i>
    <div class="transmission-map__step transmission-map__step--direct"><small>直接作用对象</small><strong>卖药公司</strong><p>药价 × 销量决定产品收入</p></div>
    <i>→</i>
    <div class="transmission-map__step"><small>公司内部选择</small><strong>现金流、研发预算与管线组合</strong><p>可能增加、削减或重排研发投入</p></div>
    <i>→</i>
    <div class="transmission-map__step transmission-map__step--indirect"><small>间接作用对象</small><strong>CXO 订单</strong><p>管线数量和工作量变化后才传到服务需求</p></div>
  </div>

  <p>所以集采和医保谈判不直接改 CXO 的合同工价。它们先作用在卖药公司的产品经济性，再通过研发预算、管线选择和生产安排间接影响外包需求。</p>
</section>

<section class="research-section" aria-labelledby="make-or-buy">
  <header class="research-section-head"><div><p>MAKE OR BUY / 自建还是外包</p><h2 id="make-or-buy">规模只是变量之一，不是唯一规则</h2></div></header>
  <div class="knowledge-coordinate">
    <div><small>影响自建</small><strong>长期稳定需求、核心工艺、资本能力</strong><p>企业可能为了控制关键产能而自建，也可能保留战略产能。</p></div>
    <b>↔</b>
    <div><small>影响外包</small><strong>需求波动、特殊工艺、速度与全球产能</strong><p>大品种也可能继续使用 CDMO，生物药和 ADC 的建厂门槛尤其高。</p></div>
  </div>
  <p>“早期量小找 CXO，规模大就自建或找更便宜代工”只能描述部分情形，不能当作行业规律，更不能从集采直接推出。</p>
</section>

<section class="research-section" aria-labelledby="seller-questions">
  <header class="research-section-head"><div><p>SELLER / 进入卖药公司</p><h2 id="seller-questions">研究恒瑞、百济等公司前先定位四组节点</h2></div></header>
  <ol class="knowledge-checklist">
    <li><strong>产品身份：</strong>收入来自创新产品、原研存量、仿制药，还是多种组合？</li>
    <li><strong>管线阶段：</strong>主要价值在发现、临床、获批放量，还是成熟产品？</li>
    <li><strong>专利与替代：</strong>保护还在不在？仿制药或生物类似药什么时候进入？</li>
    <li><strong>支付状态：</strong>药价主要受医保谈判、集采、自费市场还是院外渠道影响？</li>
  </ol>
  <p>公司答案需要回到具体药品、适应症、专利、医保目录和财务披露。本页只提供问题坐标。</p>
</section>

<section class="research-section" aria-labelledby="cxo-boundary">
  <header class="research-section-head"><div><p>BOUNDARY / 与 CXO 的边界</p><h2 id="cxo-boundary">卖药公司和替药企打工的公司不是同一种收入模型</h2></div></header>
  <div class="modality-matrix modality-matrix--two">
    <div class="modality-matrix__head"><span>公司类型</span><strong>卖什么</strong><strong>主要直接变量</strong><strong>项目失败后的影响</strong></div>
    <div class="modality-matrix__row"><strong>卖药公司</strong><span>自己的药品</span><span>临床成功、获批、药价、销量、专利</span><span>产品价值和后续收入可能大幅归零</span></div>
    <div class="modality-matrix__row"><strong>CXO</strong><span>研究、开发或生产服务</span><span>客户研发预算、管线数量、工作量与产能</span><span>已完成工作通常已收费，后续大单可能消失</span></div>
  </div>
  <p>外包角色继续看 <a href="/投资/投研/医药/研究地图/CXO与CRDMO/#roles">CXO 与 CRDMO</a>；药从发现到上市的两条线看 <a href="/投资/投研/医药/研究地图/创新药研发全流程/#parallel">创新药研发全流程</a>。</p>
</section>

<section class="research-section" aria-labelledby="open">
  <header class="research-section-head"><div><p>OPEN / 学习模型与待补证</p><h2 id="open">当前学习模型与仍待补证</h2></div></header>
  <div class="known-unknown">
    <article><h3>当前框架</h3><ul><li>创新属性、原研来源、参比指定和仿制关系需要分维度理解</li><li>原研产品在保护到期后仍可继续销售，替代产品在旁边进入</li><li>医保谈判与集采通常先作用在卖药公司的产品价单</li><li>传到 CXO 需要经过研发预算、管线与生产安排</li></ul></article>
