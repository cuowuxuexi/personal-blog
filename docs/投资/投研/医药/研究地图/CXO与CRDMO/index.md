<section class="research-section" aria-labelledby="relation">
  <header class="research-section-head"><div><p>RELATION / 关系地图</p><h2 id="relation">先认缩写，再映射到 R/D/M</h2></div></header>
  <div class="relation-map">
    <div class="relation-map__root"><strong>CXO</strong><p>医药外包服务行业总称。下面按“研究 / 开发 / 生产”能力边界拆分，而不是按公司品牌拆分。</p></div>
    <div class="relation-map__grid">
      <div class="relation-map__item"><strong>CRO</strong><p>Contract Research Organization。偏研究：发现、临床前、临床研究等。</p></div>
      <div class="relation-map__item"><strong>CMO</strong><p>Contract Manufacturing Organization。偏生产：按既定工艺代工制造。</p></div>
      <div class="relation-map__item"><strong>CDMO</strong><p>Contract Development and Manufacturing Organization。开发工艺 + 生产。</p></div>
      <div class="relation-map__item"><strong>CRDMO</strong><p>Contract Research, Development and Manufacturing Organization。研究 + 开发 + 生产，尽量覆盖更长链路。</p></div>
    </div>
  </div>
</section>

<section class="research-section" aria-labelledby="roles">
  <header class="research-section-head"><div><p>ROLES / R、D、M</p><h2 id="roles">用于拆外包服务的工作性速记</h2></div></header>
  <p>这里的 D 主要指与 CMC、工艺和制造放大相关的开发，不等于医药语境中所有“Development”。临床开发等工作也可能由 CRO 承担，现实服务边界会重叠。</p>
  <p class="graph-scroll-hint">移动端可横向滑动查看完整表格。</p>

  <div class="role-span-map" role="group" aria-label="CRO CMO CDMO CRDMO 与本文 R D M 速记的对应关系">
    <div class="role-span-map__head"><span>服务类型</span><strong>R · 研究服务</strong><strong>D · 工艺/制造开发</strong><strong>M · 生产</strong></div>
    <div class="role-span-map__row"><strong>CRO</strong><span class="role-span-map__cell role-span-map__cell--on">研究</span><span class="role-span-map__cell">—</span><span class="role-span-map__cell">—</span></div>
    <div class="role-span-map__row"><strong>CMO</strong><span class="role-span-map__cell">—</span><span class="role-span-map__cell">—</span><span class="role-span-map__cell role-span-map__cell--on">按工艺生产</span></div>
    <div class="role-span-map__row"><strong>CDMO</strong><span class="role-span-map__cell">—</span><span class="role-span-map__cell role-span-map__cell--on">开发工艺</span><span class="role-span-map__cell role-span-map__cell--on">生产</span></div>
    <div class="role-span-map__row"><strong>CRDMO</strong><span class="role-span-map__cell role-span-map__cell--on">研究</span><span class="role-span-map__cell role-span-map__cell--on">开发工艺</span><span class="role-span-map__cell role-span-map__cell--on">生产</span></div>
  </div>

  <ul>
    <li><strong>R 不是整条创新药流水线。</strong>在这套服务模型中，它概括研究服务；找分子、实验与临床研究都可能由不同类型 CRO 承担。</li>
    <li><strong>本文的 D 聚焦怎么把产品稳定造出来。</strong>包括工艺、分析方法、杂质、质量标准和放大，但不囊括所有临床或产品开发含义。</li>
    <li><strong>M 是真正生产。</strong>临床样品与商业大货都属于制造供货，只是规模和要求不同。</li>
    <li>CRO、CDMO、CRDMO 不是互斥的标准盒子；自称 CRDMO 也不代表每一段都同样强。</li>
  </ul>
</section>

<section class="research-section" aria-labelledby="parallel-link">
  <header class="research-section-head"><div><p>LINK / 与流程图连接</p><h2 id="parallel-link">D/M 在临床前就已经出现</h2></div></header>
  <p>在 <a href="/投资/投研/医药/研究地图/创新药研发全流程/#parallel">创新药双线图</a> 中，临床线持续产生药效和安全证据；制造线同时开发工艺并供应临床样品。在典型常规路径中，III 期后通常进入上市申请，但这不是 D/M 的起点，也不是所有项目唯一的监管路径。</p>
</section>

<section class="research-section" aria-labelledby="modalities">
  <header class="research-section-head"><div><p>CAPABILITY STACKS / 制造能力栈</p><h2 id="modalities">常见能力栈会重叠，不能只分三个互斥盒子</h2></div></header>
  <p>下面只列帮助入门的典型制造语境。ADC 本身连接生物与化学能力；多肽、寡核苷酸等合成新分子也不能简单塞进经典小分子或抗体工厂。</p>
  <p class="graph-scroll-hint">移动端可横向滑动查看完整表格。</p>

  <div class="modality-matrix" role="group" aria-label="常见药物制造能力栈与公司边界参照">
    <div class="modality-matrix__head"><span>能力栈</span><strong>核心工艺</strong><strong>厂与人才</strong><strong>边界参照</strong></div>
    <div class="modality-matrix__row">
      <strong>经典化学药 / 小分子</strong><span>化学反应、合成路线、杂质与纯化</span><span>反应釜、合成车间、化学工艺团队</span><span>化学 CDMO 服务语境</span>
    </div>
    <div class="modality-matrix__row">
      <strong>多肽 / 寡核苷酸等合成新分子</strong><span>仍大量依赖合成、纯化与分析，但工艺和设备要求不同</span><span>专门产线、复杂分析与放大能力</span><span>不能直接等同经典小分子</span>
    </div>
    <div class="modality-matrix__row">
      <strong>生物药 / 抗体</strong><span>细胞株、细胞培养、蛋白纯化</span><span>生物反应器、无菌蛋白线、生物工艺团队</span><span>Samsung Biologics 等生物 CDMO 语境</span>
    </div>
    <div class="modality-matrix__row">
      <strong>ADC / 生物偶联</strong><span>抗体 + Linker / Payload + 偶联</span><span>连接生物、化学、高活与偶联能力</span><span>混合能力栈，不是完全独立于生物药的单一类别</span>
    </div>
  </div>

  <p>三星生物不能直接拿来对比化学 CRDMO，不是因为给药方式，而是因为细胞培养与化学合成使用不同的工艺、设备、质量体系和人才。药明康德、药明生物、药明合联只能作为学习边界提示；具体公司归属与业务范围必须以各自披露为准。</p>
</section>

<section class="research-section" aria-labelledby="outsourcing">
  <header class="research-section-head"><div><p>OUTSOURCING / 为什么外包</p><h2 id="outsourcing">客户买效率、能力和弹性，不是让 CXO 合资赌药</h2></div></header>

  <div class="knowledge-route-grid">
    <article><span>CAPITAL</span><h3>厂贵，也可能闲</h3><p>药未获批前就自建 GMP 产线，项目失败后可能留下闲置资产。</p></article>
    <article><span>PEOPLE</span><h3>全套人马难以自养</h3><p>尤其小型 Biotech 未必能同时拥有发现、工艺、质量和商业生产团队。</p></article>
    <article><span>SPEED</span><h3>多条管线要并行</h3><p>外部平台可以比临时扩编和建厂更快地补齐能力。</p></article>
    <article><span>SPECIALTY</span><h3>工艺与合规是专门活</h3><p>放大、杂质、分析方法、GMP 和全球申报需要长期积累。</p></article>
  </div>

  <div class="knowledge-chain" aria-label="CXO 收入与客户项目推进关系">
    <span><small>客户输入</small><strong>研发预算与管线数量</strong></span>
    <i>→</i>
    <span><small>合同服务</small><strong>R / D / M 工作量</strong></span>
    <i>→</i>
    <span><small>当前收入</small><strong>服务费 / 生产费</strong></span>
    <i>→</i>
    <span><small>项目成功后</small><strong>可能出现更大后端订单</strong></span>
  </div>
  <p><strong>CXO 通常不赌药最终成功。</strong>已完成的合同工作通常会收费；项目失败会让后续订单消失，项目成功则可能带来更大的临床后期或商业化订单。</p>
</section>

<section class="research-section" aria-labelledby="business-model">
  <header class="research-section-head"><div><p>MODEL / CRDMO 为什么不只是代工厂</p><h2 id="business-model">行业故事与公司证据要分开</h2></div></header>
  <div class="process-map">
    <div class="process-map__step"><span>A</span><div><strong>更早进入项目</strong><p>若从前端研究或开发阶段进入，客户关系建立更早。</p></div></div>
    <div class="process-map__step"><span>B</span><div><strong>技术连续性</strong><p>工艺、分析方法、质量体系一旦建立，切换供应商成本会升高。</p></div></div>
    <div class="process-map__step"><span>C</span><div><strong>后端放量</strong><p>项目若推进到后期或商业化，单项目收入规模可能扩大。</p></div></div>
    <div class="process-map__step"><span>D</span><div><strong>项目池逻辑</strong><p>前端项目数量 → 推进成功率 → 后期/商业化项目数 → 产能利用率 → 收入与利润释放。</p></div></div>
  </div>
  <p>“一家陪到底”是 CRDMO 在卖的商业意图。客户是否因此更难切换、项目转化率是否更高、后端利润是否更好，都是公司研究问题，不能从缩写直接推出护城河。</p>
</section>

<section class="research-section" aria-labelledby="understanding">
  <header class="research-section-head"><div><p>UNDERSTANDING / 我的当前理解</p><h2 id="understanding">我的当前理解</h2></div></header>
  <p>如果只把药明康德当成“代工厂”，我会漏掉它为什么强调端到端服务与客户粘性。反过来，如果把 CRDMO 理解成“一定能赚到后端放量”，又会高估转化率。真正要继续验证的是：前端项目如何进来、如何留下、如何转化为后期和商业化收入。</p>
</section>

<section class="research-section" aria-labelledby="payment-boundary">
  <header class="research-section-head"><div><p>PAYMENT / 与支付端的边界</p><h2 id="payment-boundary">集采不直接改 CXO 工价单</h2></div></header>
  <div class="knowledge-chain knowledge-chain--muted">
    <span><small>支付政策</small><strong>集采 / 医保谈判</strong></span><i>→</i><span><small>直接作用</small><strong>已上市药价</strong></span><i>→</i><span><small>药企经营</small><strong>现金流与研发预算</strong></span><i>→</i><span><small>间接作用</small><strong>CXO 管线与订单</strong></span>
  </div>
  <p>完整关系见 <a href="/投资/投研/医药/研究地图/原研仿制与支付端/#transmission">支付传导节点</a>。药物规模变大后是否自建、继续外包或更换供应商，是产能、工艺、资本和供应链选择，不是“规模够大必然从 CXO 毕业”的规律。</p>
</section>

<section class="research-section" aria-labelledby="open">

  <div class="known-unknown">
    <article><h3>当前学习模型</h3><ul><li>CRO、CMO、CDMO、CRDMO 可用本文 R/D/M 速记建立初步边界，但现实服务会重叠</li><li>工艺制造开发与临床供货在临床前后持续推进</li><li>不同分子与产品需要不同且可能交叉的能力栈</li><li>外包需求与资本、人才、速度和专业能力有关</li><li>支付冲击通常先经过卖药公司，再间接影响 CXO</li></ul></article>
