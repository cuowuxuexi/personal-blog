<section class="research-section" aria-labelledby="relation">
  <header class="research-section-head">
    <div><p>RELATION / 关系地图</p><h2 id="relation">关系地图</h2></div>
  </header>
  <div class="relation-map">
    <div class="relation-map__root">
      <strong>CXO</strong>
      <p>医药外包服务行业总称。下面按“研究 / 开发 / 生产”能力边界拆分，而不是按公司品牌拆分。</p>
    </div>
    <div class="relation-map__grid">
      <div class="relation-map__item">
        <strong>CRO</strong>
        <p>Contract Research Organization。偏研究：发现、临床前、临床研究等。</p>
      </div>
      <div class="relation-map__item">
        <strong>CMO</strong>
        <p>Contract Manufacturing Organization。偏生产：按既定工艺代工制造。</p>
      </div>
      <div class="relation-map__item">
        <strong>CDMO</strong>
        <p>Contract Development and Manufacturing Organization。开发工艺 + 生产。</p>
      </div>
      <div class="relation-map__item">
        <strong>CRDMO</strong>
        <p>Contract Research, Development and Manufacturing Organization。研究 + 开发 + 生产，尽量覆盖更长链路。</p>
      </div>
    </div>
  </div>
</section>

<section class="research-section" aria-labelledby="basics">
  <header class="research-section-head">
    <div><p>BASICS / 已确认的基础知识</p><h2 id="basics">已确认的基础知识</h2></div>
  </header>
  <ul>
    <li>CRO 帮客户做研究；CMO 帮客户生产；CDMO 同时做工艺开发与生产。</li>
    <li>CRDMO 试图把研究、开发和制造连成更长服务链。</li>
    <li>行业趋势上，CRO 常往后端延伸，CDMO 常往前端延伸，边界会模糊。</li>
    <li>CRDMO 并不替客户承担药物成败的全部风险；它卖的是能力、交付与产能，不是包治百病。</li>
  </ul>
</section>

<section class="research-section" aria-labelledby="model">
  <header class="research-section-head">
    <div><p>MODEL / CRDMO 为什么不只是代工厂</p><h2 id="model">CRDMO 为什么不只是代工厂</h2></div>
  </header>
  <div class="process-map">
    <div class="process-map__step"><span>A</span><div><strong>更早进入项目</strong><p>若从前端研究或开发阶段进入，客户关系建立更早。</p></div></div>
    <div class="process-map__step"><span>B</span><div><strong>技术连续性</strong><p>工艺、分析方法、质量体系一旦建立，切换供应商成本会升高。</p></div></div>
    <div class="process-map__step"><span>C</span><div><strong>后端放量</strong><p>项目若推进到后期或商业化，单项目收入规模可能扩大。</p></div></div>
    <div class="process-map__step"><span>D</span><div><strong>项目池逻辑</strong><p>前端项目数量 → 推进成功率 → 后期/商业化项目数 → 产能利用率 → 收入与利润释放。</p></div></div>
  </div>
  <p>我目前的理解是：CRDMO 的价值不只在“能生产”，而在“能不能在更长链路中留下客户，并把一部分项目送进后端放量”。这仍是工作假设，不是已验证的公司结论。</p>
</section>

<section class="research-section" aria-labelledby="understanding">
  <header class="research-section-head">
    <div><p>UNDERSTANDING / 我的当前理解</p><h2 id="understanding">我的当前理解</h2></div>
  </header>
  <p>如果只把药明康德当成“代工厂”，我会漏掉它为什么强调端到端服务与客户粘性。反过来，如果把 CRDMO 理解成“一定能赚到后端放量”，又会高估转化率。真正要继续验证的是：前端项目如何进来、如何留下、如何转化为后期和商业化收入。</p>
</section>
