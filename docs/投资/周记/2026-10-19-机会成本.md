**《中国办公 Agent 用户行为报告》2026年9月版（LobsterAI）的有趣发现提炼：**

### 1. 场景：编程仍是绝对主力，但设计/创作在升温
- **泛编程/IT** 仍占 **40.1%**（环比上升），是第一大场景。
- **设计/影视/创作** 升至 **17.2%**，成为第二大用途，升温明显。
- 金融/财务、教育、电商、互联网运营等传统场景份额在下降，工程制造、行政人事、政府略有上升。

### 2. 任务越来越“重”：单次任务规模暴涨
- 从3月的 **6.3万 tokens** 增长到9月的 **20.2万 tokens**，约 **3.2倍**。
- 用户越来越敢把复杂、长周期的工作直接丢给 Agent。

### 3. 城市与深夜行为很有意思
- 活跃用户城市 Top10：北京(5.7%)、上海、广州、深圳、杭州、成都、南京、武汉、**郑州**(1.9%)、东莞。郑州首次进入前十。
- **重庆用户深夜最“卷”**：晚上10点到凌晨2点的调用占比高达 **19.1%**，远超广州(13.9%)、深圳(13.4%)等城市。

### 4. 微信是绝对主力入口，早高峰靠IM派活
- IM 派活渠道：**微信 77%**、飞书 14.3%、QQ 6.5%、企业微信 5%。
- 早上 **7-11点**，用户更喜欢通过 IM（而非桌面）给 Agent 派活，很多是通勤时就开始安排工作。

### 5. 国庆假期节奏明显变化
- 使用高峰从日常的下午4点左右，**推迟到晚上10点**。
- 凌晨0-7点份额从13%升到17%，白天玩、晚上回来用 Agent 干活的特征明显。
- 假期中 **泛编程/IT** 份额反而上升（+4.0%），学习教育、个人生活事务也上升；数据表格、翻译润色等下降。

### 6. 模型使用习惯与“省钱”差异巨大
- 近七成普通用户只用 **1个模型**，重度用户平均用 **2.4个**（更爱搭配）。
- **DeepSeek V4 系列缓存命中率极高**（多在95%+），实际费用可低至原价的 **4.6%~7.5%**。
- 对比：Qwen 约18.5-18.8%、Kimi 20.2%、GLM 29.6-35.1%。缓存策略差异可导致成本相差数倍甚至更多。

### 7. 模型厂商份额变化
- 智谱 GLM 环比 **暴增约166.7%**（新模型带动）。
- DeepSeek 基本持平，Qwen、MiniMax、Kimi 都出现明显下滑。

### 8. 图像/视频生成：豆包 Seed 系列称王
- 图像生成：豆包 Seedream **57.2%**。
- 视频生成：豆包 Seedance **54.4%**。
- 两者都超过一半份额。

### 9. 用户规模在加速增长
- 月度日均活跃用户持续上升，9月环比增长约 **83%**。

**一句话总结**：Agent 已经从“能对话”走向“真干活”，任务越来越重、使用越来越日常（微信+早高峰+深夜重庆），而模型层面的缓存与成本优化正在成为关键差异点。设计/创作场景的崛起和假期使用模式的变化，也显示出它正在渗透更广泛的办公与生活场景。

### DeepSeek V4.1 Flash 大规模推理部署实践

</div>

<WeeklyEntry
  tags="AI产业链研究/DeepSeek"
  title="DeepSeek V4.1 Flash 大规模推理部署实践"
  link-href="https://zhuanlan.zhihu.com/p/2095560295930508953"
  date="2026-10-20"
>

根据当前网页中 DeepSeek 官方发布的《[DeepSeek V4.1 Flash 大规模推理部署实践](https://zhuanlan.zhihu.com/p/2095560295930508953)》，关于 **V4.1 的硬件成本、收益结构及约束条件** 总结如下：

### 一、 硬件投入与成本结构

* **异构与通用算力选型**：
* **Prefill 阶段**：采用市面常见的 **8 卡标准机器**，在显存足够前提下使用较小并行度（EP2～8 / DP2～8）。
* **Decode 阶段**：采用常见的 **64～128 卡超节点**（Wide-EP），最大化并行度以提升 Batch Size 与矩阵乘法效率。
* **Vision Encoder**：采用单卡部署，官方建议选用**可用范围内最便宜的卡**即可。
* **芯片兼容性**：跨平台适配英伟达与华为昇腾等多种厂商计算芯片。


* **存储与网络基础设施**：
* **独立持久化存储**：引入独立 [3FS 分布式文件系统](https://github.com/deepseek-ai/3FS) 集群，提供约 **100 PiB 的 SSD 存储**，专门用于存储 Block KVCache（约 112 KiB 随机读写，峰值聚合读带宽达 10 TiB/s，写带宽约 850 GiB/s）。
* **网络与内存换入**：跨机 SWA KVCache 拉取使用 400G VLAN；显存与主机 shm 数据换入采用 GDR 技术，利用 RDMA 打满 PCIe 带宽，避免占用 GPU SM 算力。


* **计算开销优化（降低算力冗余）**：
* **SWA Bounded Replay**：放弃了 V4 技术报告中极占 SSD 容量的精确落盘与长序列重算，转为只重算最近 128 个 token，使前向与解码重算代价降为常数，总 Prefill 计算量近乎减半。



---

### 二、 收益与产出结构

* **集群服务吞吐**：单一集群服务吞吐达到 **155 万亿 Tokens/天**。
* **商业/算力变现收益**：按低谷电/算力价格（谷价）计算，整体收入达到 **每卡每小时 38 美金**。
* **KVCache 复用收益**：
* Agent 流量的 KVCache 保留时长（TTL）达 **3 天（72 小时以上）**，Chatbot 流量达 **7 天**，大幅减少长上下文及 Agent 场景的 Prefill 重复计算开销。
* 短期 SWA KVCache 内存池周转生命周期约 180 秒，线上命中率达 **98% 以上**。


* **解码加速收益**：配合 DSpark 变长验证投机解码，相比固定验证 5 个 token，在线部署场景吞吐提升了 **6%**；同时借助异步调度实现 GPU 无缝打满（全程无空闲）。

---

### 三、 核心约束条件与系统边界

1. **硬件与拓扑约束**：
* **大通信域单点故障风险**：在 Wide-Decode（EP64～128）下，整个实例内全部显卡构成单一通信域，**任意一张卡故障会导致整个实例不可用**，重启恢复达分钟级。
* **容错与弹性机制**：必须依赖配额冗余（占用率 > 0.8 时禁止缩容）和请求级动态重新路由；重启时需按当前存活的健康卡动态重定 EP 规模。


2. **SWA 截断与重算约束**：
* 最大前缀命中长度受 YOCO 截断约束，上限为 $L - 134$（128 窗口 + 6 投机回退）。
* SWA KVCache 必须对齐 128 tokens 整数倍存储；若 SWA 未命中，必须回退 128 tokens 进行 Bounded Replay 重算。


3. **负载均衡多维约束**：
* **Decode 阶段**：需同时约束并平衡“并发请求数”（决定 Batch 大小）与“KVCache 总长度”（决定注意力开销）两个维度。
* **Prefill 阶段**：依赖拟合的二次代价模型 $\text{cost}(q, c)$ 按纳秒级时间预算动态反解切分 token 数（Chunk Size 不固定）。
* **动态扩缩容下线延迟**：Decode 实例缩容下线设置了 **1 分钟宽限期**，以防长尾请求被直接中断，超时后未完成请求及缓存需全量转发迁出。

# 离岸信托税收新规：对话总结

## 一、核心结论

中国2026年离岸信托税收新规，最重要的变化不是提高税率，而是改变了纳税时点：把部分原本可能等到股票出售后才缴纳的资本利得税，提前到了股权装入离岸信托时。

这可能造成一个问题：

创始人没有卖出股票、没有获得现金，却因为将股权装入信托而产生巨额税款，最终可能被迫减持或质押股票。

这是本轮讨论中最值得关注的政策争议。

## 二、我们形成的六点认识

1\. 直接持有股票与装入离岸信托，税务处理不同。

对于中国税收居民个人，直接持有上市公司股票，即使股价上涨几十倍，只要没有发生应税转让，通常不需要为账面增值缴纳资本利得税。

但把升值股权装入适用新规的离岸信托，即使没有实际出售，也可能产生纳税义务。

2\. 税款按完整的历史增值计算，不是只计算上市后的涨幅。

一般计算方式：

\[
\text{应纳税额}=(\text{装入时公允价值}-\text{计税成本}-\text{合理费用})\times 20\%
\]

原始成本通常需要通过实际出资、股份取得、历史重组等资料确定，并由税务机关核查。公司上市本身不会自动把原始计税成本提高到IPO价格。

3\. 离岸信托新规主要堵住税收递延空间。

过去，中国已经有全球所得征税和反避税规定，但离岸信托部分环节的税务处理不够明确。

新规进一步明确了资产装入、信托存续收益及终止清算等环节的征税规则。

因此，过去的离岸信托不能一概称为合法免税工具，新规也不只是简单取消某项既有免税优惠。

4\. 中国的装入环节规则相对严格，但不是国际独有。

美国对某些外国信托也要求立即确认资产增值；英国部分信托可以符合条件地递延资本利得税；日本和美国某些信托可以在税务意义上的资产所有人未改变时，不立即确认转让所得。

所以更准确的评价是：

中国新规针对离岸信托装入环节的即时征税要求较严格，缺少部分国家针对特定信托设置的明确递延例外。

但不能笼统认为欧美日韩都允许离岸信托延税。

5\. 政策目标与经济后果需要分开评价。

反避税目标具有明确的税收征管逻辑。

但政策可能没有充分区分以财富传承、长期持股为目的的信托，与以规避或长期递延纳税为目的的安排。

对于历史成本低、当前市值高的创始人股权，集中纳税可能造成较大现金流压力。

6\. 富豪被迫卖股具有合理机制，但不能直接解释港股整体下跌。

已披露案例说明，部分富豪确实在减持股票或寻求融资。

但缺少补税相关减持的总体规模及市场影响数据，因此不能证明这轮补税是恒生科技指数大跌的重要原因。

## 三、以 MiniMax 为例

我们讨论了港股上市公司 MiniMax（稀宇科技）。

招股书披露，创始人闫俊杰通过 Alpha EXP 相关架构持有约6,259万股，并在上市前设立了家族信托。

但需要明确区分：

| 概念         | 含义                      |
| ---------- | ----------------------- |
| 股票面值       | 公司设立时确定的名义金额            |
| IPO价格      | 上市时公开发行股票的价格            |
| 装入信托时的公允价值 | 判断装入环节应税增值的重要依据         |
| 原始计税成本     | 通过实际取得股份、出资及历史调整确定的税务成本 |

不能把股票面值直接当作创始人的原始计税成本，也不能直接用IPO价格计算上市前装入信托时的税款。

目前公开资料不足以准确确定闫俊杰的个人计税成本、相关股份装入信托时的公允价值及实际税务义务。

另外，MiniMax存在境外控股架构，需要进一步区分装入信托的是上市公司股份还是中间持股公司的股权。

## 四、整个讨论的逻辑链

创始人长期持有升值股权

没有出售，也没有取得现金

为了传承或治理，将股权装入离岸信托

新规可能要求确认历史增值所得

即使没有实际变现

产生大额现金纳税需求

可能出现股票减持、质押融资或调整持股架构

具体影响取决于资金储备及税款规模

## 五、最后归纳为一个三段论

假设： 创始人将长期持有的股权装入离岸信托，主要用于财富传承与股权管理，实际并不准备出售。

推演： 中国2026年新规可能在装入信托时，对此前积累的股权增值征税，使创始人在没有实际现金收入的情况下承担纳税义务，增加被迫出售或质押股票的可能性。

结论： 新规有助于堵住利用离岸信托递延和规避税收的空间，但也可能提高正常长期持股型信托的经济成本。因此，其反避税目标与即时征税方式之间，存在值得讨论的政策权衡。

整个对话最终凝练成一个问题：

> 如果创始人只是改变股权持有形式，没有出售股份，也没有实质改变经济受益关系，税法是否应该立即对多年累积、尚未变现的股权增值征税？

这既是中国离岸信托新规中值得研究的争议，也是比较不同国家税收制度设计时最重要的切入点。
