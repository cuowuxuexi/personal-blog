# 优化后流程

前提：方案三步已落地（目录自动认、固定上传口、Agent 两句话）。这是改完以后你怎么走。

对照：[方案.md](./方案.md)

## 一句话

研究在投资系统里做完。你把草稿带到本仓，说「写入博客」。这家已经有档案，就在它下面新开一章。交来 HTML，标题直达这份 HTML；交来 Markdown，才改写成档案页。

## 分界

| 在哪 | 做什么 | 交出去的是什么 |
| --- | --- | --- |
| 投资系统 | 研究和战役：画布 → HTML → 草稿 | 一份你认为可以公开的稿 |
| 你 | 换到本仓，把稿交给 Cursor 或其他 Agent | 文件、路径，或直接贴进对话 |
| 本仓 Agent | HTML：落 `public/html/` + 章节标题直达；Markdown：改写成档案页 | 读者点标题看到的页 |
| 你 | 看预览，再说「上传」 | 上线许可 |

本仓 Agent 默认不回投资系统重做研究。稿是你交来的。交来的 HTML 就是读者点标题打开的那一页，不要嵌进档案壳。

## 谁干什么

| 谁 | 干什么 | 不干什么 |
| --- | --- | --- |
| 你 | 在投资系统里做完研究和战役；把草稿带到本仓；说落在哪家公司、这一次是档案根还是新开一章；图谱加不加；说「上传」 | 不改站点配置，不拼上传命令 |
| 本仓 Agent | 按稿落页；HTML 标题直达；预览；只提交这次写入的文件 | 不重做研究；不把 HTML 嵌进 iframe；不夹带周记/面板半成品 |
| 机器 | 扫文头长出侧栏和清单；构建；`push main`；传到 cuowo.cn | 不自动同步投资系统；不自动发布；不编图谱角色 |

## 读者看到的页

档案根仍是完整档案页。交来的 HTML 章节：点标题就进那份 HTML 整页，不再套一层 VitePress。

```text
第一次写入恒瑞
  /投资/投研/医药/恒瑞医药/
        │
        ▼
后来又有一次研究结果
  /投资/投研/医药/恒瑞医药/<这一次的标题>/
```

行业页「跟踪标的」仍只有一张恒瑞卡。侧栏在恒瑞下面展开各章。新章不是往恒瑞首页再堆一个标题。

周记里的拼多多表是嵌进周记正文。投研 HTML 章节走标题直达，和历程 cli篇同一条。

## 你对 Agent 说的话

| 你说 | Agent 走哪条 | 回不回投资系统 |
| --- | --- | --- |
| 「写入博客」 | HTML：落公开 HTML + 章节标题直达；Markdown：档案根或新章节 → 预览 → 等人闸 | 不回 |
| 「上传」 | 只提交这次写入的文件 → 固定上传口 → 对一下国内 SHA | 不回 |
| 「按投资系统改认识」 | 回源 → 改正文 → 预览 → 等人闸 | 回 |
| 「新开一个行业」 | 先停，问行业壳怎么铺 | 按你点头再动 |

没说「上传」，只写入、只预览，不上 cuowo.cn。

交稿时最好说清：哪一行业、哪家公司、这一次的标题。没说标题、这家已有档案，Agent 应问一句再开新章，不要默默改首页。

## 日常四条路

### 路 A：交稿写入（最常见）

```text
投资系统
  研究 / 战役 / 画布 → HTML → 草稿
        │
        ▼
你换到本仓，把草稿交给 Agent
  「写入博客」
        │
        ├─ 这家还没有档案
        │    docs/投资/投研/<行业>/<公司>/index.md
        │
        └─ 这家已经有档案
             docs/投资/投研/<行业>/<公司>/<标题>/index.md
             HTML：public/html/<名字>/ + 文头 publicHref
             恒瑞首页加一条指向这一章的链接（HTML 链到 /html/<名字>）
        │
        ▼
档案根仍是完整档案页。HTML 章点标题进画布整页。
        │
        ├─ 你要进图谱？写出那一句
        │
        ▼
本地预览：行业页只见公司、侧栏能进章节、HTML 章直达 /html/<名字>
  不改 config.mts
        │
        ▼
你说「上传」
        │
        ▼
只提交这次写入的文件 → push main → 固定上传口
```

### 路 B：某一页认识变了

带着改过的稿说「写入博客」，改那一页。稿没带过来才说「按投资系统改认识」。

### 路 C：只挂地图、暂不建档案

只改地图上的一句。没有档案目录，清单和侧栏都不会出现这家。

### 路 D：新开一个行业

先说「新开一个行业」，点头后再建行业壳。有草稿再按路 A 写入第一家。

## 一次「写入博客」实际几步

1. 你把草稿放到对话里，并说落在哪家、标题是什么。
2. Agent 按稿落页：新公司写档案根；已有公司开新章。HTML 落 `public/html/`，标题直达；Markdown 写成档案页。
3. 本地预览行业页、侧栏、这一页。
4. 你说「上传」。
5. Agent 只挑这次写入的文件提交，push，走固定上传口。
6. 打开线上页，看国内站 SHA。

中间没有：重开 Gate 1、回投资系统重做战役、把 HTML 嵌进 iframe、手改侧栏、夹带其它半成品。

「写入博客」不再重走 Gate 1。没说「上传」就不推、不传。

## 你还要亲自盯的三件事

1. **交过来的稿对不对** — 博客按这份稿落页；HTML 就是读者点标题打开的那页。
2. **图谱写不写** — 机器不替你判断卖药还是 CXO。
3. **能不能上线** — 只有你说「上传」。
