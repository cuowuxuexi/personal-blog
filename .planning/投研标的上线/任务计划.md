## 关键问题
1. 「自动认新标的」现在到底差哪一截（侧栏、对账、主题组件）？
   总览组件和主题注册已有。差侧栏接线，以及把「医药必须 N 家」改成活对账。
2. 投研上传能否复用现有 `uploadDist`，而不开放面板编辑投研？
   能。命令或面板「上传当前站点」只调构建 + `uploadDist`，不开放投研编辑。
3. Agent 何时回源投资系统，何时只做登记和发布？
   默认交稿口「写入博客」不回源。只有作者说「按投资系统改认识」才回源。「上传」只发布。

## 已做决策
- 研究和战役在投资系统做完（画布 → HTML → 草稿）。作者自己把草稿带到本仓，交给 Agent「写入博客」。
- 本仓 Agent 的默认工作是写入和上线，不是重做研究。不自动同步指挥部。
- 投研标的读者面只要完整档案页（恒瑞那种壳）。画布 HTML 只是投资系统草稿，写入时改写成 Markdown，不走独立 HTML / `<StandaloneHtml>`。
- 一家公司一个档案根。后续新研究结果在该公司下新开一章，仍是完整页，不往首页堆标题。
- 行业清单只显示公司。侧栏在公司下展开章节。现在投影还不认章节页，步 1 要补。
- 新行业 ≠ 旧行业下加一家公司。
- 知识图谱上的业务位置仍手写。
- 面板不改成投研编辑器；最多加「上传当前站点」。
- 人闸保留：作者说「上传」才传 cuowo.cn。
- 作者已批，开始改代码。未获「上传」不 push、不传 cuowo.cn。
