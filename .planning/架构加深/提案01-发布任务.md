# 提案 01：把发布任务拆成三段

状态：已按中档批准（2026-08-24）。批准不等于改代码。

## 一句话

你还是只点一次「确认发布」。门里面拆成三段：准备、执行、上线核对。问进度只问、不干活。

## 小 / 中 / 大 是什么意思

用你发一期周记的那天来讲。

**小档：只堵一个撒谎的口。**  
页面每两秒问一次「到哪了」。现在这一问，可能顺便继续对国内站。小档只改这件事：问就只问。你点确认时，里面仍是一锅粥。改得少，以后改「怎么对国内站」还是要翻整锅。

**中档：你只点一次，里面分成三段。**  
- 准备：打包快照、做出隔离预览和公众号预览、给你确认令牌。不动 Git，不上线。  
- 执行：提交、推送到 Git。  
- 上线核对：把生产构建传到 cuowo.cn，再看国内站的版本号是不是这次的提交。  

问进度仍然只问。失败后的「重试推送 / 重试验证」还是现在那两个按钮，要你亲自点。  
本文按这一档写。它和仓库里已有的模块化计划阶段 5 一致，又不去改按钮上的字、也不去改网址名字。

**大档：中档再加改门口牌子。**  
连按钮文案、网址路径一起改名。和后面「拆面板界面」那条抢活。这次不做。

## 你已经定下的

- 先写提案，不改代码。  
- 作者侧只点一次确认发布。  
- 按中档拆三段。

## 现在哪里别扭

今天的顺序其实已经是：先「准备发布」，你看清单和预览，再「确认发布」。门禁没坏。

别扭在门里面：

1. **问进度会干活。** 状态若是「已推送 / 正在部署 / 正在核对」，页面去问进度时，会接着上传或对国内站。刷新页面、两秒一次的轮询，都可能推着发布往前走。出错时你分不清：是刚才那次确认还在干活，还是「问一下」又开了一趟。  
2. **确认把后两段捆死。** 一次确认里提交、推送，再进上线核对。上线核对自己又包含「第一次上传」和「反复问国内站版本号」。以后你只想改核对，会碰到提交推送；只想改推送，会碰到国内站。  
3. **门口和里面一样宽。** 准备、确认、读取、重试推送、重试验证、查公众号图，都从同一坨发布任务往外伸。学一个门口，等于把整张流程表背下来。

删除测试：把「发布任务」整块删掉，提交、推送、上传、对 SHA 的规矩会散到面板网页、服务入口和测试里。所以这块要留，而且值得加深——不是删掉。

## 改完你怎么用（应该和今天一样）

1. 保存内容。  
2. 点准备发布，看隔离预览和清单。准备不是发布。  
3. 点一次确认发布。浏览器会再问你一句「要推 Git、上传 cuowo.cn」。  
4. 等国内站版本号对上这次提交，才算发布完成。海外备份仍是 `push main` 之后的 Cloudflare。  
5. 推送失败，你点「重试推送」。国内站没对上，你点「重试验证」。  
6. 公众号预览、复制前查图，还是现在那些按钮。

不改成你点三次。不改成自动发布。投研仍然不能从面板发。

## 门里面怎么拆（仍是人话）

**准备**  
吃你刚保存的那份内容，列出能发的文件，做出隔离预览。给你一枚只能用于这一份快照的确认令牌。失败就停在准备，不会碰到 Git。

**执行**  
只有拿着有效令牌、状态是「预览已就绪」才能进来。做提交和推送。做完停在「已推送」。不要在这一段里对国内站。

**上线核对**  
只有已经推上去的任务才能进来。需要的话先上传国内站，再问国内站版本号。对上了才是「已发布」。超时或对不上，停在失败，并告诉你可以「重试验证」。

**问进度**  
只回报状态、清单、预览地址、能不能重试。不上传，不对版本号，不推 Git。

刷新页面或确认那一下的网络断了、核对还没结束：由明确的「继续核对」接着干。面板自动帮你发这一下，你不用多点一个按钮。这和「问进度」不是同一件事——一个只看，一个才干活。

Git、构建、SSH 上传仍是插在接缝上的适配器（真环境和测试各一套）。不再套一层空壳。

公众号查图仍是旁边的明确动作，不塞进这三段的门口。

## 不改什么

- 你要点两次的节奏：先准备，再确认。确认仍是一次。  
- 公开网址、正文、站点样子。  
- 国内站 cuowo.cn、海外备份 blog.cuowo.win。  
- 发布门禁：没有你的确认，不提交、不推送、不上传。  
- 面板范围：只有周记和历程；不加投研。  
- 不创建、不改名、不删除历程的具名篇章。  
- 不改按钮上的字，不改网址路径（那是大档，留给后面面板界面那条）。  
- 不重写公众号预览怎么渲染。  
- 不把「问进度」改成自动发布。

## 改完怎么算验收

用你平时的发法走一遍，再走失败：

1. 准备发布后，能打开隔离预览；此时 Git 上还没有这次提交。  
2. 不点确认，只让页面问进度：国内站版本号不变，任务状态也不该被「问一下」推去。  
3. 点一次确认：出现提交、推送、国内站对上；你没有多点「执行」或「核对」。  
4. 发布完成页能打开已校验的国内站地址。  
5. 人为让推送失败：只出现「重试推送」，问进度不会偷偷再推。  
6. 推送成功但国内站对不上：只出现「重试验证」，问进度不会偷偷再传。  
7. 现有面板测试要全过。本条不扩到改周记保存、不扩到改投研目录。

## 和下一条怎么错开

- 本条不改「草稿其实立刻写盘」。那是提案 02。  
- 本条不改「哪些路径能发写了三遍」。那是提案 03。  
- 本条不拆面板网页那份总管家。网页只跟着改一件事：问进度不再干活；核对没结束时自动发「继续核对」。那是提案 04 的范围。
