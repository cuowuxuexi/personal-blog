# 提案 05：投研目录只声明一次

状态：已按「改刚好」批准并落地（2026-08-24）。验收见 `验收报告.md`。

## 一句话

文章里的话还是你写。行业、地图、标的、哲学主题排在哪、侧栏怎么列，只声明一次，构建时自己长出来。面板仍然不碰投研。

## 小 / 中 / 大 是什么意思

**少改：** 只投影投研侧栏。行业总览页上的地图清单、标的清单还手写。Cursor / Pi 加一页仍可能漏改总览。

**改刚好（本文按这个写）：**  
投研、投资哲学、大问题都接上和周记同一套办法：结构声明一次，侧栏由构建长出来。总览页上「有哪些地图、有哪些标的、有几张图」这类清单和数字，能生成的就生成；暂时生成不好的，先严格对账——手写和声明对不上就失败，不许悄悄各写各的。

页面上的判断、学习路径、开篇说明，仍写在 Markdown 里。比如医药页「先判断卖什么」那两张路径卡，是你的叙事，不自动编。

**改太多：** 让面板也能改投研，或从私有投研指挥系统自动同步正文。不重开那两条决定。这次不做。

## 你已经定下的

- 先写提案，不改代码。  
- 投研不进发布面板（提案 03）。  
- Cursor / Pi 改投研又慢又容易错，这一条先治「改一页要动好几处」。若做完还不够，再单独谈要不要给投研做面板。  
- 博客不是私有投研的镜子。  
- 投研默认不进首页「最近更新」。

## 现在哪里别扭

周记、历程已经是：正文写在文章里，目录构建时自动长出来。

投研还不是。加一张研究地图或一份标的档案，今天通常要：

1. 写那篇 Markdown；  
2. 在站点侧栏里再挂一个链接；  
3. 在行业总览或地图总览上再写一行。

投资哲学、大问题也是侧栏手写一份，总览页再写一份。哲学主题比投研树浅，但抄两遍的病一样。

所以 Cursor / Pi 一改就容易漏：侧栏有了、总览没有，或链接写错、数字还写着「3 张图」。不是模型笨，是结构没有单一接缝。

删除测试：把「类型化信息架构 + 构建投影」删掉，加一页又要改 N 处。所以值得留，而且值得做成和周记同一深度。

## 改完你怎么用

**你或 Cursor / Pi 改一页投研时：**

1. 正文、判断、学习路径、开篇说明：只改那篇 Markdown。  
2. 它在树里的位置（哪个行业、是地图还是标的、排第几、侧栏显不显）：只在结构声明里写一次。  
3. 侧栏和总览清单跟着构建更新。不用再去 `config.mts` 里手插一行。  
4. 发布仍走现在的投研门禁：先说清楚再写，预览后再推。不是面板确认发布。

**读者看到的：**

公开网址不变。页面气质不变。首页最近更新仍然没有投研，除非你以后明文批准某一种再进。

## 门里面怎么改（仍是人话）

**Markdown 拥有叙事**  
介绍、当前理解、开放问题、路径卡上的判断，都还是文章里的话。

**结构只声明一次**  
行业、研究地图、标的档案、哲学主题、大问题条目：谁是谁的孩子、什么顺序、读者看不看得到、状态标签从哪来。周记已经用的那份内容目录，往这边接；没有种类的（哲学、大问题）补登记，不另造一套。

**构建长出侧栏**  
`/投资/投研/`、`/投资哲学/`、`/大问题/` 的侧栏不再手写树。和周记受管侧栏同一条投影路。

**总览清单**  
「有哪些地图、有哪些标的、几个」尽量由同一份结构长出来。医药页那种「先判断卖什么」的叙事卡不自动编。生成不好的清单，先对账：手写和声明不一致就让测试失败。

**面板不参与**  
写入文章、准备发布、确认发布，都不对投研开放。

## 不改什么

- 公开网址、已有正文观点。  
- 私有投研指挥系统仍是事实和正式结论的权威。  
- 没有自动同步、没有自动发布。  
- 投研不进面板。  
- 研究地图不是写完的教科书；标的档案不是一次性研报。  
- 不拆发布任务、不改保存、不改面板三件工作（提案 01–04）。  
- 不收拢三套文头解析（提案 06）。  
- 不把实验性的医药三页拆法冻成所有行业的永久模板——结构声明可以按行业长，版式仍以你预览后为准。

## 改完怎么算验收

1. 新加一张研究地图或一份标的档案：只改 Markdown + 一处结构声明；侧栏出现正确链接；对应总览的清单或数字一致，或不一致时测试失败。  
2. 现有医药 / 互联网 / 猪肉 / 白酒 / 硬件、哲学四篇、大问题「开源与闭源」的公开网址不变。  
3. 首页最近更新里仍然没有投研页。  
4. 从面板准备发布，仍不能把投研文件打进清单（跟提案 03 同一条）。  
5. 内容目录测试、站点构建要过。本条不改你点面板的步骤。

## 和「Cursor / Pi 改内容容易错」的关系

这一条让它们少改几处：结构一处，叙事一处。不能保证再不写错判断，但能少漏侧栏、少漏总览。

若做完你还是觉得改投研太疼，再单独谈面板——那是新产品，要重谈谁预览、谁点发布。
