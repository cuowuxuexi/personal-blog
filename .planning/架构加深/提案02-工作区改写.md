# 提案 02：保存就是写入文章

状态：已按「改刚好」批准并落地（2026-08-24）。验收见 `验收报告.md`。

## 一句话

点保存，还是马上改仓库里的周记/历程。只把「已经写入文章」和「还在输入框里的备份」分开叫；扔掉早就没人用的改目录旧代码。

## 小 / 中 / 大 是什么意思

**少改：** 只删掉那些还会改 `posts.ts`、侧栏的旧函数和对应测试。保存还叫草稿。

**改刚好（本文按这个写）：**  
少改那些都做。另外把「写入文章」单独说清楚，门里面不再把这件事叫草稿。你眼睛看到的字：主按钮讲明白是保存到文章；已经写进文件的提示，不再说草稿。浏览器自动备份、以及「清空草稿」，仍叫草稿——因为那份还没进文章。

**改太多：** 连拆条、改期头、列目录、网址路径一起改名。和第 4 条「整理面板页面」抢活。这次不做。

## 你已经定下的

- 先写提案，不改代码。  
- 保存之后，文章马上变。不改成「确认发布才落盘」。  
- 按「改刚好」来。  
- 按钮改一句实话。网址路径这次不动。

## 现在哪里别扭

你平时的用法没坏：写 → 保存并预览 → 再确认发布。保存完就能在工作区预览里看到。

别扭在两件事挤在同一个「草稿」里：

1. **输入框里的备份。** 你还没点主按钮，面板自己记一份，刷新还能找回来。「清空草稿」清的是这个。这个叫草稿，是对的。  
2. **点主按钮之后。** 仓库里的 Markdown 立刻被改掉，目录不再手改（构建自己长出来）。门里面却还叫 `applyDraft`、走 `/api/draft`，有的提示还说「草稿已写入」。名字在骗人。

另外，文件里还留着早年往 `posts.ts`、侧栏里插字的旧刀法。现在保存已经不走它们，测试还在养。删掉它们，麻烦跟着消失——不值得加深，该扔。

删除测试：把「写入文章」整块删掉，追加、改条、删条、开新期、改期头会散到面板各处。所以写入文章要留，而且值得单独说清楚。

## 改完你怎么用（应该和今天一样）

1. 打字时，面板照旧自动备份。刷新后还能问你要不要恢复。不要就点「清空草稿」。  
2. 点主按钮：文章马上写入仓库，并去做发布前预览。这不是发布。  
3. 你看预览和清单，再决定点不点「确认发布」。  
4. 润色、贴图、开新期、改期头、改条目、删条目，都还是先写入文章，再预览。

不改成「保存了文章还没动」。不自动发布。投研仍然不能从面板写。

## 门里面怎么改（仍是人话）

**写入文章**  
门口只做一件事：按你选的做法（追加、修改、删除、开新期、改期头），把 Markdown 写进工作区，告诉你改了哪些文件、预览链到哪。目录和侧栏不在这里手改。

**表单草稿**  
还没写入文章的输入框备份。读、写、清空只动这份。不要和写入文章共用一个名字。

**扔掉的**  
往 posts、侧栏里插字或改字的旧函数，以及只为它们活着的测试。保存路径不再经过它们。

**你眼睛看到的字**  
- 主按钮现在写「保存并生成发布预览」。改成「保存到文章并生成发布预览」，把「已经写进文件」说破。  
- 「清空草稿」不动。它清的是还没进文章的那份。  
- 提示里凡是「文件已经改了还叫草稿」的，改成「已写入文章」这类实话。例如现在的「请先保存草稿」「草稿已写入」。  
- 网址仍叫 `/api/draft`。改网址留给第 4 条，避免一次改两摊。

## 不改什么

- 一点保存就写进 Markdown。  
- 先保存并预览、再确认发布的节奏。  
- 公开网址、正文观点、站点样子。  
- 发布门禁：保存不是发布。  
- 面板范围：只有周记和历程。  
- 不创建、不改名、不删除历程的具名篇章。  
- 不改发布任务怎么拆（那是提案 01）。  
- 不改哪些路径能发写了三遍（那是提案 03）。  
- 不拆整份面板总管家（那是提案 04）。  
- 不收拢三套文头解析（那是提案 06；写入文章可以继续用现在这份解析，收拢另做）。

## 改完怎么算验收

1. 追加一条、改一条、删一条、开新一期、改期头：对应 Markdown 立刻变；`posts.ts`、侧栏文件没有被这次保存改掉。  
2. 没点主按钮就刷新：还能恢复输入框里的备份；点「清空草稿」只清备份，不删已经在仓库里的文章。  
3. 点主按钮后，提示说的是写入了哪些文章，不再说「草稿已写入」。  
4. 主按钮能看出「会写进文章」。  
5. 旧的插 posts / 插侧栏函数已经不在，也不再有只测它们的测试。  
6. 现有面板测试要全过（去掉那些旧刀法测试之后）。本条不改发布确认，不改投研目录。

## 和下一条怎么错开

- 本条不拆发布任务。那是提案 01。  
- 本条不统一「哪些文件能发」。那是提案 03。  
- 本条只改保存这一句人话和门里面的名字；不改整页怎么拆。那是提案 04。
