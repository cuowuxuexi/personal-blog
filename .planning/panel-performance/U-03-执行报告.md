## 交付

一次确认、confirm token、发布清单 fail-closed、`.new → 原子替换` 与 `build.json` 的 sha/builtAt 契约未改。`uploadDist` 在上传前写入稳定 SHA-256 清单 `.panel-dist-manifest.json`：

- 远端清单可读，且 `manifest.sha` 与远端 `build.json` / `expectedBaselineSha` 一致时走增量：只打包 added/changed。
- `production-check` 把 `job.baseSha` 经 `probes.deploy` 传给 `uploadDist` 的 `expectedBaselineSha`。
- full 与 delta 远端切换共用 `${siteDir}.deploy-lock`：`mkdir` 原子占有，成功后 `trap EXIT rmdir` 释放；mkdir 失败不碰别人的锁。
- fetch 时保留可信清单原文的 SHA-256 摘要。delta 在持锁后、`cp -a` 前用 `sha256sum < manifest | awk` 核对摘要；不一致则本次 delta 失败。
- `uploadDist` 捕获该失败后走现有全量 fallback；full 也受同一锁保护。锁被占用时 delta 与 full 都失败，不并发覆盖。
- full/delta 共用一个上传/apply/清理 helper：每次 SCP 到注入安全、任务唯一的远端 tar（随机 16–32 hex，不能只用目标 SHA），成功、apply 失败、锁忙都尽力 `rm -f` 自己的 tar，不删其他任务归档。本地归档清理保持。
- 缺清单、JSON 损坏、路径不安全、基线不匹配或增量准备/SSH 失败时 fail-closed 回退全量 tar。
- 清单路径与摘要拒绝注入；打包排除 `release-preview/` 与 `.panel-*` 候选/预览元数据。
- 测试桩完成全部 SSH/SCP/tar；无真实上传、发布或部署。未跑 `docs:build`。

## Repair round 2

缺口：读到清单 A 后、`cp -a` 前若生产被切到 B，会把 A→C 的 delta 铺到 B 上，`build.json` 变成 C，核对可能误绿，未变文件残留 B。

关闭方式：同一 `${siteDir}.deploy-lock` + 持锁后核对 fetch 时清单原文摘要。摘要漂移 → delta 失败 → 全量 fallback（此时锁已由 trap 释放）。锁仍被占用 → full 也 mkdir 失败 → 整个 `uploadDist` 抛错，不覆盖。

未改生产目录语义：仍是 `.new → 原子替换`；锁是与 `.new`/`.old` 并列的兄弟目录，不引入 rsync 或交互命令。

## Repair round 3

缺口 A：`uploadFull` / `uploadDelta` 在拿到 `siteDir.deploy-lock` 前，都 SCP 到同一个固定 `safe.remoteTar`。两个并发任务可先后覆盖该文件；之后拿到锁的任务可能解压另一任务的归档。

关闭方式：`uniqueRemoteTarPath` 在模板路径（默认 `/tmp/blog-dist.tar`）上插入任务唯一 hex id；full/delta 都走 `transferAndApply`（SCP → apply → 尽力 `rm -f` 自己的 tar + 本地归档清理）。共享锁继续只保护目录复制/切换。唯一 id 拒绝注入、大写、以及 40/64 位 SHA，避免只靠目标 SHA 命名。

缺口 B：`production-check.mjs → probes.deploy → uploadDist` 只传目标 sha，没有传 `expectedBaselineSha`。远端清单自身 well-formed 时，即使 `job.baseSha` 不一致也会走增量。

关闭方式：`job.baseSha` 经 `probes.deploy` 传给 `uploadDist`。远端 manifest/`build.json` 与预期不一致时仍全量回退。一次确认、confirm token、发布状态机、`build.json` 与验证轮询语义未改。

## 原则

- KISS / YAGNI：锁、唯一 tar 与守卫收在 `guonei.mjs`；`production-check` 只多传一个字段。
- DRY：full/delta 共用 `withProductionDeployLock` 与 `transferAndApply`。
- 单一职责：摘要不一致只让本次 delta 失败；锁竞争安全失败；远端 tar 清理只删本任务路径。
- 不新增运行时依赖，不要求 Windows rsync。
