# 方案：Agent 速度与准确性护栏

输入来源：2026-08-25 对话（面包屑任务复盘 → CLI 建议 → Skill 停读判定）。  
不是新产品方案；只把已确认的护栏写成可执行包。

## 目标

1. 圈选 DOM / 唯一定位后打开目标文件即停读。
2. 独立 HTML 假导航（祖先链到 `#hub`）用命令红灯，不默认开浏览器。
3. 预览是否可连用一行命令判定，并消除 `docs:dev` 只听 `::1` 的坑。

成功尺子（同一条昨日任务）：打开 `cli-hub/index.html` → 改父级 href → `pnpm check:html` 绿；不读 `site-design` / catalog / 主题；不启动浏览器 MCP。

## 非目标

- 新 HTTP / Agent 总控 / `pnpm verify` 总控（阶段 6）
- Playwright 或浏览器 MCP 当链接回归
- `pnpm where`、自然语言路由
- 把 `target="_top"` 写进规范
- commit / push / 发布 / 部署（除非批准档另行允许）
- 整理或提交工作区里其它已有改动

## 三层

1. **Skill 停读**：`blog-editor` Startup 写成可判定完成条件；`assets` 默认证据改为 `pnpm check:html`。
2. **CLI**：`pnpm preview:ready`、`pnpm check:html`；`docs:dev` 绑 `127.0.0.1`。
3. **验收分层**：href 用 `check:html`；预览用 `preview:ready`；视觉才开浏览器。

## 权威

- 公开路由：`content-catalog`（`contentSiteLink` / `publicHref` / 投影 link）
- 独立 HTML 落盘：`docs/.vitepress/standalone-html.mjs` 的 `standaloneHtmlFile`
- Agent 路由：`.agents/skills/blog-editor/SKILL.md`（不在 `AGENTS.md` 再抄一遍）
